# 狼人杀本地试玩

运行 `npm run games:preview`，打开 `http://127.0.0.1:5185/game-preview.html`。此入口复用应用界面，使用独立的本地对局服务；没有替换已安装的客户端。

本地模型配置位于 `.local/game-model.json`，不纳入 Git。需要 `baseUrl`、`model`、`apiKey`、`contextTokens`，当前试玩服务通过 Responses 调用该模型，并统一用于所有 AI 玩家。不启用网页搜索或工作工具。浏览器只取得模型名称，不取得密钥。

群聊输入框点击「AI 游戏」，选择狼人杀，勾选自己或取消勾选以旁观，点击「一键补齐」后开始。真人被分配随机身份，夜间可能需要选择目标；白天轮到自己时提交发言和投票。AI 自动执行，不需要手动推进。出局后可以继续旁观。全知视角仅供全 AI 对局使用。

七人规则：2 狼人、1 预言家、1 女巫、3 村民。狼人夜间选择非狼人目标，多数优先，平票按目标座位靠前者执行；预言家每晚查验一人。无遗言，出局不公开身份。白天按存活座位顺序发言，秘密投票收齐才公开。平票重投一次，再次平票无人出局。狼人全部出局则好人获胜；狼人数量不少于好人则狼人获胜。女巫在狼人和预言家完成行动后用药，夜间死亡统一结算。整局一瓶解药、一瓶毒药，每晚最多使用一瓶；仅首夜可自救，解药耗尽后不再获知刀口。暂不包含队内自由讨论、警长和猎人。

真人每次发言120秒，AI发言60秒，夜间行动与投票45秒。到时未提交则跳过发言、弃权投票或放弃夜间行动，并记录原因。暂停冻结剩余时间，继续恢复计时；结束对局需要确认并留下带时间的操作记录。

模型调用失败会有限重试，仍失败则暂停，可以继续重试或结束。主动暂停、恢复、终止均保留已接受行动；退出页面不停止服务。退出服务后，在下次启动时对局恢复为暂停状态，由用户继续。最多运行 20 天，达到上限暂停而不虚构胜负。

对局保存在 `.local/game-data/matches.json`，包含私有身份和查验记录，请将它视为本地私有数据。凭证仅在 `.local/game-model.json` 中。

应用代码已接入相同规则与运行器的 Electron IPC，使用应用既有模型服务；试玩服务是独立的本地验证入口。当前只实现狼人杀，不代表已完成通用多游戏框架。脚本规则测试与 Grok 实战只能证明已覆盖的路径，不能证明模型策略水平。

本次新增的「运行记录」及已复现问题见 [可观测性与问题记录](./werewolf-observability.md)。旧对局缺少模型输入与耗时，无法补录。

新对局为七人局，旧局保留原人数。AI 开局随机分配不同的性格倾向，本局持久保存；模型发言建议 120–220 字、3–6 句，信息不足时允许更短。提示要求回应他人、保持公开宣称的一致性，并允许狼人伪装和拉票；这不是策略质量保证，尚未实现独立的结构化长期策略状态。运行记录以座位号、名字和中文动作展示，隐藏内部请求编号。
