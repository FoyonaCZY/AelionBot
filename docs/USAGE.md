# 使用帮助

这里补充工作目录、任务规划与操作许可的具体使用方式。

## 工作目录、计划与目标

- 输入框左下角的 **＋** 可以上传附件、制定计划或执行目标。把文件夹拖进输入框，可以打包成附件发送。
- 工作目录在 **Bot 资料**、**群聊设置**或**工作会话设置**里修改，按单聊、群聊或工作会话分别保存；本机命令的默认目录和文件的相对路径使用该目录。已经开始的任务保留原目录，更换目录不会增加操作权限。
- 输入 **`/plan 任务内容`**，Bot 先调查并生成带有验收条件的步骤清单。计划显示在输入框上方，点击 **开始执行** 后才允许实际修改项目。
- 输入 **`/goal 目标内容`**，Bot 会建立目标并持续执行、核对结果；遇到阻碍会说明原因。卡片支持暂停、继续、查看步骤和完成依据。达到运行预算或应用退出时保留进展，不自动重复执行。
- Bot 也能在已授权的任务范围内主动设置计划或目标，使用同一套步骤、执行记录和权限机制。输入 `/` 可以选择指令，附件、粘贴和 `@` 提及仍然可用。

## 本机权限模式

在 Bot 主会话输入框底部选择权限模式。设置按 Bot 保存，从群聊接下的工作也跟随这个设置，群聊没有独立的权限选择。

- **每次询问**：命令、文件和 MCP 调用每次等待确认，不套用自动放行规则。
- **自动审批**：工作目录内普通文件的读取、创建、编辑，以及可明确识别的简单文件命令，由本地规则直接放行，不消耗审核模型 Token。敏感配置、越界写入、MCP 调用和其他未匹配的操作交给应用的默认模型审核。你已保存的命令规则仍可生效；模型审批本身不产生长期权限。
- **完全访问**：Bot 的本机操作和 MCP 调用直接执行。VM 人工接管仍需要你处理。

自动审核不放行、未配置默认模型或审核失败时，会回到会话内请你确认。切换模式会重新处理尚未执行的请求，取消任务会撤销审核，过期的审核结果不能继续执行操作。

项目内编辑采用本地规则的设计参考了 [Claude Code 的权限模式](https://code.claude.com/docs/en/permission-modes) 和 [Gemini CLI 的写入策略](https://github.com/google-gemini/gemini-cli/blob/main/packages/core/src/policy/policies/write.toml)。本机权限模式是应用的执行审批层，不是操作系统沙箱。

## 长期记忆

Bot 会记住以后还用得上的事。设置 → 记忆 里可以看到、修改和撤销它记下的所有内容。

- **不用说“记住”**：一段对话安静 90 秒后，应用用一次模型请求读这段对话，记下长期事实和做过的事。说了“记住”“更正”“忘记”的，当场生效。
- **四个范围**：关于你（所有 Bot 共用）、每个 Bot 自己的、每个项目的（按 git 仓库，多个克隆共用）、每个群的。旧版本的记忆留在原来的 Bot 里，像是关于你的条目会出现在“等你确认”，你同意后才让所有 Bot 知道。
- **回复下方的“想起了 3 条 · 记住了 1 条”**：点开能看到是哪几条，不对就点“这条不对”或“撤销”。
- **来源决定可信度**：只有你说过的话和本地工具的实际结果才能成为事实。网页、MCP、附件和其他 Bot 的内容不会变成事实；读过这些内容后 Bot 自己想记的，要你确认。其他人在连接器里说的话只留在那个 Bot，并标明是谁说的。
- **不想被记住**：在消息里说“这次不要记”；输入框左边的 + 菜单可以让这段对话不记入记忆；设置里可以让某个 Bot 只用不记，或者完全不用；角色扮演类的 Bot 可以关掉“使用关于你的记忆”。
- **空闲时整理**：应用会合并重复的、拆开混在一起的、归档过时的，每次都记在“整理记录”里，可以整次撤销。没用过的旧事实只是归档，不会删除。
- **语义检索**：在本机运行一个约 25 MB 的小模型（bge-small-zh-v1.5），模型文件第一次使用时下载，内容不会发出去。关掉或下载失败时，按词搜索照常工作。
- **遗忘**：点“忘记”后，这条记忆的文字会从数据库和修改历史里清除，也不会再被自动记回来；但原始对话还在，已经发给模型服务的内容也无法追回。

后台提取和整理默认用每个 Bot 自己的模型，可以在记忆设置里换成便宜的。这些用量在“用量”里单独显示。

## 知识库

知识库是你起了名字的一组文件夹或文件。应用在这台电脑上给它们建立索引，Bot 回答时可以检索其中的内容并注明出自哪个文件。在 设置 → 知识库 里新建和管理。

- **添加来源**：一个知识库可以放多个文件夹和单独的文件。文件夹会包含子文件夹；`.gitignore` 里忽略的文件、`node_modules` 这类目录、隐藏文件和隐藏文件夹不收录。
- **支持的文件**：Markdown、纯文本、常见的代码和配置文件、HTML、PDF、Word（docx）、PowerPoint（pptx）和 Excel（xlsx）。扫描件这类没有文字的 PDF、有密码的 PDF 和过大的文件不收录，页面上会列出是哪些文件、为什么。
- **谁可以用**：默认所有 Bot 都能检索，也可以只给选定的 Bot。Bot 在私聊、工作会话、群聊和连接器里都能用；命令行里不提供。
- **全部在本机**：索引存在应用的数据目录里，文档不会上传。Bot 检索到的片段会随对话发给它使用的模型服务，和它读文件时一样。
- **保持更新**：新建或修改来源后会自动索引；应用启动后会检查一次，Bot 检索时如果距上次检查超过十分钟也会在后台再检查。只重新读有变化的文件。点“重新索引”会把所有文件重读一遍。
- **语义检索**：用的是长期记忆的那个本地模型，在 设置 → 记忆 里开启。开启后换个说法也能找到；没开时按关键词检索，照常可用。
- **上限**：一个知识库最多收录 5000 个文件，超过时只收录前 5000 个，页面上会提示。
- **权限不变**：把文件夹加进知识库，只表示允许 Bot 读已经索引的片段。Bot 要打开整份原文件，仍然走原来的读取权限和审批。
- **来源不在时**：移动硬盘没插上这类情况下，已经索引的内容会保留，页面上提示找不到来源。删除知识库只删索引，不动你的文件。

## 搜索、导出和重新生成

- **搜索所有对话**：侧栏的搜索除了按名字筛 Bot、会话和群，还会在下方列出聊天记录里匹配的消息，包括已归档的工作会话和群聊。点一条会打开那个对话并定位到这条消息。多个词用空格隔开时要求同时出现。只搜你和 Bot 的正文，不搜工具输出。
- **导出对话**：在侧栏右键点 Bot、工作会话或群聊，选“导出对话”，保存成 Markdown 文件。里面有每条消息的说话人、时间、正文和附件名；Bot 的处理步骤只记步数，推理内容不导出。
- **重新生成**：对话里最后一条回复的工具栏有“重新生成”。原来的回复会被新的替换，Bot 像第一次收到那条消息一样重新回答；已经写好的文件、执行过的命令不会撤销。确认时可以换一个模型，换了之后这个 Bot 会一直用它。群聊里的回复、计划和目标任务、连接器发来的消息不能重新生成。

## 系统通知

窗口不在前台时，Bot 等你批准或回答、任务结束、自动化运行结束，都会发一条系统通知，点击会回到对应的对话。在 设置 → 通知 里可以分别开关，也可以关掉“显示消息内容”，只显示是哪个 Bot、发生了什么。预算提醒不受这些开关影响。

## 花费和预算

- **花费**：设置 → 用量 的概览、趋势图和模型明细按模型价格估算金额。内置价格来自 [models.dev](https://models.dev) 的公开数据，随应用打包，也可以在“预算”页点“更新价格表”取最新的。这是按当前价格的估算，不是账单；没有价格的模型会标出来，这时金额偏低。
- **自己的价格**：在“预算”页的模型价格表里可以给任何模型填价格，覆盖内置值。本机模型可以填 0。
- **货币**：美元、人民币或欧元。内置价格是美元，按你填的汇率换算，应用不联网取汇率。
- **预算**：可以设每月和每日预算，留空表示不限。用到 80% 和 100% 时各提醒一次。超出后可以选“只提醒”或“暂停自动运行”：暂停时自动化不再触发、持续目标不再自己续跑，你手动发的消息照常执行；到下个周期或调高预算后自动恢复。

## 数据备份和换电脑

设置 → 数据 里可以把对话、Bot、记忆、技能、附件和设置导出成一个备份文件（`.aelionbackup`），也可以从备份恢复。

- **密码和密钥**：API Key、连接器凭据这些是用这台电脑的系统密钥加密的，换一台电脑解不开。导出时设一个密码，它们会用这个密码另外加密放进备份，在新电脑上恢复时输入密码就能接着用；不设密码时，备份只能在原来的电脑上恢复出这些密钥，换电脑后要重新填。
- **恢复**：选备份文件、确认后，应用会重启并用备份替换现在的数据。被替换的数据会留一份，在同一页可以打开或删除。比当前应用版本新的备份不能恢复。
- **不在备份里的**：工作文件夹里的文件、工作电脑（换电脑后重新准备）、可以重新下载的模型，以及知识库的索引（恢复后自动重建；知识库的来源路径在新电脑上不存在时，页面会提示找不到来源）。

## 媒体模型

所有 Bot 使用工作区的生图、视频、语音识别和合成设置。可在「设置 → 模型」选择默认服务，Bot 也可以按任务更换生图和视频模型。配置方法见[工作区媒体模型](media-models.md)。

## Bot 文件和模板

- **导出 Bot**：Bot 的右键菜单里选“导出 Bot”，把它的名字、SOUL、形象、技能和人格存成一个文件（`.aelionbot`），可以选择带上长期记忆。聊天记录和 API Key 不在里面；模型只记服务商名和模型名。
- **导入 Bot**：新建 Bot 时点“导入 Bot 文件”，确认后新建一个 Bot。本机有同名的服务商和模型就沿用，否则用默认模型。带进来的记忆先放在“等你确认”。
- **模板**：新建 Bot 时可以从 12 个模板开始，选中后会填好名字、SOUL 和形象，之后都可以改。

## 悬浮终端

聊天右上角的终端按钮会打开一个悬浮终端，运行在这台电脑上，起始目录是当前会话的工作目录。每个会话有自己的终端。

- 拖动标题栏移动，拖动右下角调整大小。
- 隐藏后 shell 继续运行，按钮上的绿点表示它还在。点 × 或输入 `exit` 才会结束；退出应用时全部结束。
- 这里输入的命令就是你自己在运行，不经过本机权限模式，Bot 也读不到这个终端。
- 选中文字后按 Ctrl+C 复制，没有选中时 Ctrl+C 是中断；Ctrl+V 粘贴。

## 本机电脑控制

在 设置 → 权限 打开“让 Bot 操作这台电脑上的应用”后，Bot 可以观察并操作这台电脑上的应用窗口。支持 Windows 和 macOS，默认关闭。

- **能在后台做的不占用前台**：查看窗口、按控件点击按钮和勾选框、填写输入框、滚动，这些不需要鼠标和键盘。Bot 直接对窗口本身操作，窗口留在原处，你可以继续用电脑，屏幕上没有提示，`Esc` 也照常归你使用。macOS 上启动应用、从菜单栏选择命令同样在后台进行。
- **用到鼠标和键盘时才来到前台**：按坐标点击、拖动、输入文字和按快捷键使用真实的鼠标和键盘。这时目标窗口来到前台，屏幕边缘出现边框、顶部出现提示条，按 `Esc` 立即停止这次任务。提示刚出现时 Bot 会停顿片刻再动手，让你来得及松开键盘。Windows 会把新启动的应用放到前台，所以在 Windows 上启动应用也按这种方式进行。
- **有些窗口必须在前台才能看**：浏览器和基于浏览器内核的应用被其他窗口完全挡住或最小化后不再刷新画面，Bot 要看它时会先把它带到前台。露出一部分的窗口不受影响。macOS 上所有被完全挡住或最小化的窗口都按这种方式处理。
- **每个任务确认一次**：任务第一次要操控电脑时，会话里会出现确认卡片。允许之后，这个任务里不再询问，直到它结束；下一个任务会重新询问。这项确认与本机权限模式无关，完全访问模式下同样需要你确认。拒绝之后，这个任务不会再次询问。
- **macOS 需要两项系统权限**：辅助功能和屏幕录制。打开开关后，设置 → 权限 的电脑控制卡片会显示这两项是否已允许，点“去授权”跳到 系统设置 → 隐私与安全性 的对应页面。授予屏幕录制后需要重新打开 AelionBot。缺少权限时 Bot 不会开始操作，也不会弹出确认卡片。
- **不能操作的窗口**：终端应用（macOS 上还包括脚本编辑器和自动操作）、AelionBot 自身、Windows 上以管理员身份运行的窗口，以及系统的权限和安全提示。Bot 遇到这些步骤会请你处理。会离开当前应用的快捷键也不会发送：Windows 上是 Windows 键组合和 `Alt+Tab` 这一类，macOS 上是 `Cmd+Tab`、`Cmd+空格`、强制退出、锁屏和切换桌面。
- **只看到被操作的应用**：截图只包含目标应用自己的窗口，点击和输入落到其他应用上时会被拒绝。截图会发送给当前 Bot 使用的模型服务。
- **同时只有一个任务**：一个任务占用这台电脑时，其他任务的电脑操作会等待。无人值守运行不提供这个能力。

按窗口观察和操作、终端和自身不可操作，这两点对齐了 [Codex 的 Computer Use](https://learn.chatgpt.com/docs/computer-use)。Codex 按应用逐个批准，这里改为每个任务进入时确认一次。

工作电脑和本机的电脑操作都支持 `batch`：Bot 可以在一次观察后连续执行多个不会改变界面布局的动作（例如点击输入框、输入、回车），只在最后截一张图。
