# AelionBot v0.6.0

新增 macOS Apple Silicon（ARM64）与 Intel（x64）预览安装包，Windows 版本继续提供安装及自动更新。

## Mac 预览版

- 面向 macOS 15 及以上，分别提供 ARM64 和 Intel 的 DMG、ZIP。
- 随包附带对应架构的 QEMU 运行时和固件，无需自行安装 Homebrew 或 QEMU。
- Apple Silicon 使用 ARM64 Debian 工作电脑和 Chromium；Intel 使用 amd64 Debian 工作电脑和 Chrome。
- 本机命令使用 zsh，支持工作目录、命令授权、后台进程、停止和日志查询。
- 适配 Mac 标题栏、菜单、文件剪贴板与平台路径规则。

当前 Mac 包采用临时签名，尚未经过 Apple 公证。把应用拖入“应用程序”后首次打开，如果被系统拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”，并核对来源为本仓库。无需关闭系统安全保护。

Mac 预览版可以检查新版本，更新时通过 Release 下载并替换应用；暂不自动替换。正式签名、公证后的构建支持原生 Mac 更新链路。

## 工作电脑

- 按 CPU 架构选择固定镜像并验证 SHA-512，ARM 固件使用独立的可写变量文件。
- 桌面初始化按架构安装内核与浏览器，统一浏览器入口，保留每 Bot 的独立桌面与配置。
- 新工作电脑使用系统自带的 Adwaita 图标，省去体积约 200 MB、解包耗时较长的额外图标主题。
- 修正独立桌面启动时的重复初始化等待，改用有时间上限的就绪检查并清理失败的启动进程。
- 原有 Windows 工作文件继续保留；工作电脑环境升级会按需提示准备或重启。

预览包通过对应架构的 Mac 构建和应用检查。GitHub 托管 Mac 环境不支持嵌套硬件虚拟化，VM 自动化检查使用 TCG 软件模拟；实际 Mac 使用 HVF 加速，仍欢迎反馈实机兼容性问题。
