# AelionBot v0.50.1

## 简体中文

### 撤回并编辑

- Bot 还在排队或正在处理的消息，鼠标移上去多了一个“撤回并编辑”按钮。点一下，这次任务就会停止，消息和 Bot 为它写的内容从对话和模型上下文里移除，原文连同附件、提及和引用回到输入框，改完重新发送即可。输入框里已经写了的内容会保留在后面。
- 已经执行的操作（写好的文件、跑过的命令）不会撤销；任务结束后的消息不能再撤回。

### 工作会话

- 右键工作会话改为弹出菜单：编辑、Fork 到新工作会话、归档和删除。工作会话设置里只保留名称和工作目录。
- Bot 主会话和工作会话都可以 Fork：新建一个工作会话，带上最后一次完成的任务及之前的记录、模型上下文、工作目录和本机权限模式。之后进行中、失败或停止的任务不会带过去。
- Bot 的右键菜单新增“已归档的会话”，可以直接打开或取消归档；打开的已归档会话会在会话列表里淡色显示。

## English

### Take back and edit

- A message that is still waiting or being worked on now has a "Take back and edit" button in its toolbar. It stops the task, removes the message and what the Bot wrote for it from the chat and the model's context, and puts the text back in the composer with its attachments, mentions and quoted reply, ready to edit and send again. Anything already typed in the composer stays, after it.
- What the task already did (files written, commands run) is not undone, and a message whose task has ended can no longer be taken back.

### Work sessions

- Right-clicking a work session opens a menu: edit, fork into a new work session, archive and delete. The session settings keep only the name and folder.
- A Bot's main chat and its work sessions can be forked: a new work session starts with the records up to the last completed task, the model's context, the folder and the permission mode. Tasks after that, whether running, failed or stopped, stay behind.
- A Bot's menu lists its archived work sessions, to open or restore them; an archived session that is open shows faintly in the conversation list.
