# AelionBot v0.55.0

## 简体中文

### 系统通知

- 窗口不在前台时，Bot 等你批准或回答、任务结束、自动化运行结束，都会发一条系统通知。点通知会回到对应的对话。
- “设置 → 通知”里可以分别开关，也可以只显示是哪个 Bot、发生了什么，不显示消息内容。

### 搜索和导出对话

- 侧栏的搜索现在也搜聊天记录：所有 Bot 对话、工作会话（包括已归档的）和群聊里匹配的消息会列在下方，点一条就打开那个对话并定位到这条消息。
- 在侧栏右键点 Bot、工作会话或群聊，可以“导出对话”，存成 Markdown 文件。

### 重新生成

- 对话里最后一条回复的工具栏多了“重新生成”。原来的回复会被新的替换，已经写好的文件、执行过的操作不会撤销。
- 确认时可以换一个模型，换了之后这个 Bot 会一直用它。

### 花费和预算

- “设置 → 用量”按模型价格估算花费，概览、趋势图和模型明细里都能看到。内置价格来自 models.dev，也可以给任何模型填自己的价格。货币可选美元、人民币或欧元。
- 新的“预算”页签可以设每月和每日预算，用到 80% 和 100% 时各提醒一次。超出后可以只提醒，也可以暂停自动化和持续目标；你手动发的消息照常执行。
- 花费是按当前价格的估算，不是账单。没有价格的模型会标出来。

### 知识库

- “设置 → 知识库”里可以把文件夹或文件加进来，应用在这台电脑上建立索引，Bot 回答时检索其中的内容并注明出处。
- 支持 Markdown、文本和代码、HTML、PDF、Word、PowerPoint 和 Excel。默认所有 Bot 都能用，也可以只给选定的 Bot。
- 文件有变化时只重读变化的部分。在“记忆”里开启本地模型后，换个说法也能找到。

### 备份和换电脑

- “设置 → 数据”可以把对话、Bot、记忆、附件和设置导出成一个备份文件，也可以从备份恢复。恢复会重启应用，被替换的数据会留一份。
- 导出时设了密码，API Key 和登录信息会一起备份，换电脑后输入密码就能接着用。
- 工作文件夹里的文件和工作电脑不在备份里，换电脑后工作电脑需要重新准备。

### Bot 文件和模板

- Bot 的右键菜单多了“导出 Bot”，把它的设定、形象、技能和人格存成一个文件，可以选择带上记忆。
- 新建 Bot 时可以“导入 Bot 文件”，也可以从 12 个模板开始。

### Telegram、Discord 和 Slack（实验）

- 连接器新增 Telegram、Discord 和 Slack。在这些应用里私聊机器人，Bot 在电脑上干活，把最终回复和文件发回去，需要本机权限时可以直接点按钮批准。
- Telegram 里可以收发语音消息。目前只支持私聊。
- 这三个平台还没有用真实账号完整验证过，遇到问题请反馈。

## English

### System notifications

- While the window is in the background, the app shows a system notification when a Bot waits for your approval or answer, when a task ends and when an automation finishes. Clicking it opens that chat.
- Each kind can be turned off in Settings → Notifications, and notifications can show only the Bot and what happened, without the message.

### Search and export chats

- The sidebar search also finds messages: matches from every Bot chat, work session (archived ones too) and group are listed below, and clicking one opens the chat at that message.
- Right-click a Bot, work session or group in the sidebar and choose "Export chat" to save it as a Markdown file.

### Regenerate

- The last reply in a chat has a "Regenerate" button. A new reply replaces it; files already written and actions already taken are not undone.
- You can pick another model when you confirm; the Bot keeps using it afterwards.

### Spending and budgets

- Settings → Usage estimates spending from model prices, in the overview, the trend chart and the model breakdown. Built-in prices come from models.dev, and you can set your own for any model. Amounts can be shown in USD, CNY or EUR.
- A new Budget tab sets monthly and daily budgets, with one reminder at 80% and one at 100%. Past the budget the app can just remind you, or pause automations and goals; messages you send still run.
- Spending is an estimate at current prices, not a bill. Models without a price are marked.

### Knowledge bases

- In Settings → Knowledge bases, add folders or files. The app indexes them on this computer, and Bots search them when they answer and say which file an answer came from.
- Markdown, text and code, HTML, PDF, Word, PowerPoint and Excel are supported. Every Bot can use a knowledge base by default, or only the Bots you choose.
- Only changed files are read again. With the local model turned on in Memory, a search also finds passages worded differently.

### Backups and moving to another computer

- Settings → Data exports chats, Bots, memory, attachments and settings into one backup file and restores from one. Restoring restarts the app and keeps a copy of the data it replaced.
- With a password set at export, API keys and sign-ins go into the backup too, and work on another computer after you enter the password.
- Files in your work folders and the work computer are not in the backup; on a new computer the work computer is set up again.

### Bot files and templates

- A Bot's context menu has "Export Bot", which saves its settings, look, skills and personality in one file, with its memories if you want.
- When creating a Bot you can import a Bot file or start from one of 12 templates.

### Telegram, Discord and Slack (experimental)

- Connectors now include Telegram, Discord and Slack. Message the bot privately there; the Bot works on your computer and sends back its final reply and files, and you can approve local actions with a button.
- Telegram supports voice messages both ways. Only private chats are supported.
- These three have not been fully tested with real accounts yet; please report any problems.
