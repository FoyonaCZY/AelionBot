# AelionBot v0.58.0

## 简体中文

### 视频工作室

- Bot 可以用新的视频工具创建多轨视频项目、导入素材、剪辑时间轴、预览画面并导出成片。`video_project_create` 始终可用，其余工具在创建项目后或已有视频项目时自动启用。
- 预览里新增多轨时间轴编辑器：片段显示画面和波形，可以拖动移动、拖两端裁剪，并吸附到播放头和相邻片段；支持分割、删除、波纹删除、添加文字与字幕、自动压低背景音、一键去静音和响度标准化。
- 选中片段的属性固定在右侧一栏：画面填充、转场、画面效果、变速、音量和淡入淡出。
- 导出支持 MP4、WebM、GIF、WAV 和 PNG 当前帧，可选画质，完成后可作为附件发送；导出进度以浮动提示显示，可以随时取消。

### 视频预览与快速剪辑

- 文件预览里的视频换成新的播放器：进度条带缩略图和波形，标出批注位置和静音片段；支持逐帧、倍速、循环和全屏。
- 快速剪辑：裁剪并导出片段（MP4 或 WebM）、一键去静音、截取当前帧，或在视频工作室中打开。
- 视频上的批注带时间，选中批注会跳到对应位置。

### 对话

- 视频附件显示封面、播放按钮和时长。
- 视频工具调用有专门的卡片，导出时显示进度条。

### 记忆设置

- 记忆页重新设计：顶部分为“记忆”和“设置”两栏；用头像条选择关于你、各个 Bot、项目或群聊的记忆；Bot 的“使用关于你的记忆”和“记忆方式”直接在范围头部调整。
- 每条记忆显示类别、来源和日期；等你确认的记忆集中在顶部卡片，可以直接确认或拒绝。
- 语义检索、记忆模型、导入导出、最近 7 天统计和整理记录移入“设置”栏；知识库页的“开启语义检索”会直接跳到这里。

## English

### Video Studio

- Bots can create multi-track video projects, import assets, edit the timeline, preview frames, and export the result with new video tools. `video_project_create` is always available; the other tools turn on once a project is created or when the Bot already has video projects.
- A multi-track timeline editor in the preview: clips show their picture and waveform, can be dragged to move or trimmed at either end, and snap to the playhead and neighbouring clips. It supports split, delete, ripple delete, adding text and subtitles, auto-ducking background music, removing silence, and loudness normalization.
- The selected clip's properties stay in a column on the right: fit mode, transition, visual effect, speed, volume, and fades.
- Export to MP4, WebM, GIF, WAV, or a PNG of the current frame, with a quality choice and the option to attach the file to the chat when done. Export progress appears as a floating notice and can be cancelled at any time.

### Video preview and quick edit

- Videos in the file preview use a new player: the scrubber shows a filmstrip and waveform and marks comments and silent segments, with frame stepping, playback speed, loop, and fullscreen.
- Quick edit: trim and export a clip (MP4 or WebM), remove silence, capture the current frame, or open the video in Video Studio.
- Comments on a video carry their time, and selecting one jumps to that position.

### Chat

- Video attachments show a poster, a play button, and the duration.
- Video tool calls have their own cards, with a progress bar while exporting.

### Memory settings

- Redesigned Memory page: two parts, Memory and Settings; pick memories about you, each Bot, a project, or a group from a strip of avatars; a Bot's "Use memories about you" and "Memory mode" are set in the scope header.
- Every memory shows its kind, origin, and date; memories waiting for you are gathered in a card at the top where you can confirm or decline them.
- Semantic search, the memory model, import and export, the last-7-days totals, and the consolidation log moved to the Settings part; "Turn on search by meaning" on the Knowledge page opens it directly.
