# AelionBot v0.54.2

## 简体中文

### 界面统一

界面的样子没有大改。这一版把同一种东西在各个页面上的不同画法收成了一种。

- 弹窗：新建自动化、创建群聊、Bot 资料、新建工作会话、插件、AI 游戏、私聊记录这些弹窗现在是同一个外壳，圆角、阴影、标题大小、关闭按钮的位置和边距都一致。
- 输入框和搜索框：输入框统一成灰底、同一个高度。记忆页和设计页的搜索框改成和侧栏、插件页一样的灰色胶囊。
- 按钮：同一类按钮高度一致。设计页的“导入”、上下文面板的“立即压缩”改成和别处一样的灰色胶囊，弹窗的关闭按钮统一成圆形。
- 标签：插件页选中的标签不再是黑底，设计系统的分类不再是白底描边，都和设置里一样用灰色表示选中。自动化的触发方式、用量的时间范围改成和“模型分配 / Providers”一样的分段控件。
- 勾选：复选框和单选从系统默认样式改成蓝色，和开关一致。新建工作会话里选中的 Bot、外观里选中的主题和背景也用蓝色标出。
- 展开箭头：“查看诊断摘要”、人格页的说明等处的黑三角，换成和别处一样的箭头。
- 文字大小：“设置 → 外观 → 界面文字”现在对所有界面文字生效，之前有一部分文字不跟着变。
- 动效：鼠标悬停和按下的反馈在所有可点的地方一致。插件详情、状态文字、消息图钉出现时的动画，和弹窗、菜单用的是同一套。各处加载转圈的速度一致，开关不再回弹。

### 企业微信和飞书里的语音消息

- Bot 在企业微信或飞书里回复时，它录的语音会作为语音消息发出去，可以直接点开听，不再是一个音频文件。你明确要文件时仍然发文件。
- 企业微信单条语音最长一分钟，更长的回复会在停顿处分成几条。飞书是一条。
- 超过五分钟的语音、微信（没有语音消息）以及语音消息发送失败时，照旧发音频文件。
- “用语音回复 IM 里的语音消息”现在对企业微信也有效。

### 问题修复

- 修复群聊里点“成员与性格”时，面板被工作电脑卡片挡住的问题。

## English

### One consistent interface

The app looks the same at a glance. This version takes things that were drawn differently from page to page and gives each one look.

- Dialogs: new automation, new group, Bot profile, new work session, plugins, AI games and peer chats now share one shell, with the same corners, shadow, title size, close button position and margins.
- Fields and search: text fields are the same gray fill and height everywhere. The search fields in Memory and Design are gray capsules like the ones in the sidebar and plugins.
- Buttons: buttons of one kind are one height. "Import" in Design and "Compact now" in the context panel are gray capsules like the rest, and every dialog's close button is round.
- Tabs: the selected tab in plugins is no longer black and the selected category in design systems is no longer an outlined pill; both use gray, as settings does. The automation trigger and the usage time range are segmented controls like "Model assignments / Providers".
- Checkboxes and radios are drawn in blue, like switches, instead of the system default. The Bot picked for a new work session and the theme and background picked in Appearance are marked in blue too.
- Folds: the black triangle beside "View diagnostic summary", the persona page notes and similar places is the same chevron used elsewhere.
- Text size: "Settings → Appearance → Interface text" now applies to all interface text; some of it did not follow before.
- Motion: hover and press feedback is the same on everything you can click. Plugin details, status lines and message pins appear with the same motion as dialogs and menus. Loading spinners turn at one speed, and switches no longer bounce.

### Voice messages in WeCom and Feishu

- When a Bot replies in WeCom or Feishu, speech it records goes out as a voice message you can tap to hear, not as an audio file. It still sends a file when you ask for one.
- A WeCom voice message is at most a minute long; a longer reply is split at pauses into several. Feishu gets one message.
- Speech longer than five minutes, WeChat (which has no voice messages) and voice messages that fail to send still get the audio file.
- "Answer voice messages from chat apps by voice" now works in WeCom as well.
