# AelionBot v0.26.0

模型按目录单独配置，Responses 可启用服务端搜索和生图。工具并行不再受数量上限，写文件按路径加锁。会话里的内容审核、问候误带桌面快捷方式和重复附件也一并处理。

## 模型与设置

- Provider 下为每个模型预先设置上下文容量、推理强度、思考预算、图片输入，以及 Responses 内建网页搜索 / 图片生成。
- 选择默认模型或 Bot 模型时沿用目录里的值；已有 Bot 的模型选择、密钥和对话不会被覆盖。
- 启动、保存 Provider 或刷新模型列表时预热 HTTP 连接。
- 勾选服务端搜索后，不再向模型提供应用内 `web_search`；生图结果会作为附件出现在回复里。

## 执行

- 同一轮独立工具不再受并行数量上限限制。
- 工作电脑里的不同文件可以同时写入；本机写入仍逐项确认。同一路径、工作电脑操作和终端命令仍然互斥。
- 应用内网页搜索增加 Bing HTML、DuckDuckGo Lite、Brave 备用源，并缓存短时间内的重复查询。

## 会话与附件

- 打招呼不再把工作桌面的 `.desktop` 快捷方式当成产物。
- `message_attach` 可以发送本机绝对路径；已经送达的同一文件不会在后续回复里重复挂上。
- 模型服务返回内容审核（如 DeepSeek `Content Exists Risk`）时，会清掉会话里可能触发审核的工具输出，Bot 可以继续对话。
