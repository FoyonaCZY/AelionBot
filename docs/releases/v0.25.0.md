# AelionBot v0.25.0

设计师系统：独立的设计师 Bot、预装设计系统和可验证的原型 / 演示文稿交付。

## 设计师 Bot

创建或编辑伙伴时可以选择「通用」或「设计师」。设计师有自己的任务工作台、设计会话和模型历史，不走通用技能学习。切换类型会清空该伙伴的对话和记忆，文件与插件保留。

## 设计任务

- 原型（HTML）和演示文稿（可编辑 PPTX）是两类独立任务。
- 可从预装设计系统库里选风格；任务文件写在默认工作区的 `designers/<Bot>/<任务>` 下。
- 默认先交付可用初稿，深度走查和反复截图验收需要你明确提出。
- 你可以在预览里改代码、改元素、标注，保存后会记录版本；模型不会悄悄覆盖你刚保存的文件。

## 预装设计系统

安装包内置已审核的 OpenDesign 设计系统资源，含许可证。品牌风格仅为视觉参考，不是官方授权。构建不依赖外网拉取。

## 其它

- 流式回复、请求超时和用量统计对设计师任务同样生效。
- 含 v0.24.2 的群聊广播修复：普通群消息仍发给所有成员。
