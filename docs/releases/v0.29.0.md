# AelionBot v0.29.0

设计师新增项目字体库，并重新设计画布比例、标注和提问交互。本版同时包含个人称呼与游戏动作解析修复。

## 字体与导出

- 设计任务顶部新增“字体”入口，可搜索并按需下载开源字体，选择字重与样式，缓存后离线复用。
- 支持导入 WOFF2、WOFF、TTF、OTF，应用为当前 HTML 的正文、标题或代码字体，并检测文件异常与缺字。
- HTML 下载内嵌本地字体等资源，项目 ZIP 包含引用资源及字体授权记录；PDF 等待字体与图片加载完成后导出。
- 本版字体应用面向 HTML/PDF，尚不包含 PPTX 字体嵌入。

## 画布与提问

- 聊天栏保留固定宽度，画布使用剩余空间。文档默认适应宽度，提供整页、原始比例和缩放选择。
- 展开、收回画布保留页码、显示比例、标注和未发送草稿；窄窗口也能展开。
- 圈选或选择元素后可直接输入问题，修复原生网页遮挡输入框和键盘焦点停留在网页的问题。
- 标注支持选择、修改说明、删除和撤销；网页标注还支持重做。滚动、缩放和重新打开时保留坐标及元素定位。
- 问题会附上当前截图、标记和文件信息。发送失败保留草稿，成功后清空临时标注；持久批注按位置区分，避免误合并。

## 其他修复

- 明确区分 Bot 自己的名字和用户资料中的称呼，开场白与普通对话使用一致的身份信息。
- 完善狼人杀各阶段的动作格式和解析，区分女巫用毒目标与跳过、救人分支，并改进不合规回复的重试提示。
- 游戏请求遵守生成上限与剩余上下文容量，统一缺省容量，回复被截断时明确报错。
