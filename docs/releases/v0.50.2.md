# AelionBot v0.50.2

## 简体中文

### 在飞书、企业微信和微信里允许操控电脑

- 通过连接器发来的任务需要操控这台电脑时，Bot 的主人会在自己的私聊里收到一张卡片，可以直接点“允许这次任务”或“拒绝”。不支持卡片的平台（如微信）会收到文字，回复「同意」或「拒绝」即可；同时有多个请求在等待时，带上消息里的四位编号。
- 只有连接器的主人能做决定，群聊和其他人的回复不起作用。允许只对这一次任务有效，电脑前的人仍然可以按 Esc 随时中止。在电脑上先处理了的请求，卡片会显示“已在电脑上处理”。

### 后台复盘

- 使用上下文窗口很大的模型（如 500k、1M）时，后台复盘以前每次都会因为超出预算而失败，现在可以正常完成。很长的任务只取最近的部分做复盘，较早的记录需要时由复盘自己回查。
- 已经结束的复盘任务不再保留整段对话副本，长期使用后的 `cognition.sqlite` 不会再持续变大。升级后第一次启动会清理一次旧数据。

### 其他

- 计算器卡片的明细保持单列，复制按钮不再换行。

## English

### Allow computer use from Feishu, WeCom and WeChat

- When a task that came in through a connector needs to operate this computer, the Bot's owner gets a card in their private chat and can choose "Allow this task" or "Deny" right there. On platforms without cards, such as WeChat, the request arrives as text: reply "同意" or "拒绝", adding the four-character code from the message when several requests are waiting.
- Only the connector's owner decides; replies from group chats or anyone else change nothing. An approval covers that one task, and whoever is at the computer can still press Esc to stop it at any time. A request handled on the computer first shows "已在电脑上处理" on its card.

### Background review

- With large-window models such as 500k or 1M, background review used to fail every time for exceeding its budget. It now completes. A very long task is reviewed from its most recent part, and the review looks up earlier records when it needs them.
- Finished review jobs no longer keep a copy of the whole conversation, so `cognition.sqlite` stops growing over long use. The first start after updating clears the old copies once.

### Other

- The calculator block keeps its breakdown in one column, and its copy button stays on one line.
