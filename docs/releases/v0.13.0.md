# AelionBot v0.13.0

本版修复 Bot 管理和工具执行问题，并更新工作电脑与运行设置界面。仅提供 Windows x64 安装包。

- 修复删除 Bot 后技能缓存未及时清理，导致后续新建、删除及界面刷新报“Bot 不存在”的问题。
- 兼容按行读取时的 `offset: 0`、文件检索空路径及本机命令的相对工作目录。
- 调整任务完成判定：保留读取失败记录，但不再要求逐条消除探索性读取失败才能结束任务；写入和命令执行的未解决问题仍需处理。
- 移除重复的内部校验提示，Bot 头像旁按当前工具及批量子步骤显示工作状态。
- 更新工作电脑预览面板、桌面外观和壁纸，并调整运行设置表单。

## 下载

- Windows x64：`AelionBot-Setup-0.13.0-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
