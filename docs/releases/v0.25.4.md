# AelionBot v0.25.4

通用 Bot 更接近主流 coding agent：检查命令失败不再掐掉整轮对话，残缺的工具参数会交回模型继续，已经写给用户的话也不会在核对时被抹掉。

## 通用 Bot

- `go vet`、`npm test` 等非零退出只作为检查结果，不再弹出「执行遇到问题」。写入失败仍会拦住收尾。
- 工具参数不是完整 JSON 时，当作一次工具失败交回模型，不把整轮判失败，也不当网络错误去重试。
- 流式工具调用按数字/字符串 index 和 call id 拼接，避免把一条调用拆成半截。
- 核对还没结束时，已经显示过的介绍会留在对话里。
- 记忆、表态保存失败不再挡住结束；也不再让模型把执行账本写进对用户的回复。
- 工作电脑关闭后可以删除仍记着后台任务的 Bot。
- 问答回复会跟在提问气泡后面。
- 设置里输入默认模型名称时不再每敲一个字母就失焦。
