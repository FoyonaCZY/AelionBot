# AelionBot v0.24.2

恢复群聊广播，并防止未完成任务反复生成结束语。

- 移除群聊协调者和委托机制，群成员收到消息后自行判断是否回复。
- 计划或目标尚未完成时，连续三次只生成结束语而未调用工具，会停止自动重试，保留工作记录并显示原因；正常工具执行会重置计数。
- 群任务因此停止时会在群内显示提示，方便检查步骤后继续。相关反馈：#14。
- 包含默认工作区生效、默认目录修改自动保存，以及独立工具调用并行执行的更新。
