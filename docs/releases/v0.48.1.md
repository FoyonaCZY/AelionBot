# AelionBot v0.48.1

## 简体中文

### 对话

- 运行中的中间输出现在直接以气泡显示，不再藏在步骤折叠区里；工具调用之间说的话会按发生顺序出现在对话中。
- 运行完成后，中间输出和工具步骤一起收进“已处理 X · N 个步骤”；展开后仍以气泡和时间线保留，顺序不变。
- 运行中只给最后一条气泡显示头像，工具行超过 8 个才折叠；底部状态只保留当前动作标题。

## English

### Chat

- Intermediate output now appears as live bubbles while a run is in progress instead of being hidden inside the step list; text between tool calls stays in chronological order.
- When the run completes, intermediate output and tool steps collapse into “Processed X · N steps”; expanding it keeps the bubbles and timeline in the same order.
- Only the last bubble shows an avatar while running; tool rows collapse only after eight entries, and the bottom status keeps just the current action title.
