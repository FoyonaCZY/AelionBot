# AelionBot v0.5.0

本次升级执行内核，改进长任务、工具权限、模型兼容性和工作记录恢复，并加入计划与目标管理。

## 执行与权限

- 阅读已注册的技能、发现和读取已启用 MCP 的工具目录、资源及模板不再反复申请权限；明确声明只读的 MCP 工具可以直接运行，有副作用的调用保留确认。
- 每次工具调用独立记录目标与结果，修复“另一个文件成功掩盖之前失败”的问题。未知结果不会当作成功，也不会在重启后自动重放。
- 设置新增运行预算、请求重试、超时、并行读取数量及进度汇报间隔；短任务不再每三个工具调用额外请求模型汇报。
- 支持批量读取、后台任务与日志查询、持续 Python 会话，以及带验收条件和执行回执的 Bot 委托任务。
- 较大的文件内容、代码和回滚数据通过标准输入传输，避免命令长度限制。

## 模型、上下文与技能

- Provider 新增 Responses、Claude Messages、Gemini Generate Content 协议，保留 OpenAI 兼容接口；支持原生模型列表、推理参数及可选备用模型。
- 改善限流、连接中断和不完整响应的恢复；流式重试会清理旧预览，完整解析之后才执行工具。
- 单聊与群聊共用上下文压缩、摘要校验和原文回查机制；保留原生推理元数据与工具标识。
- 技能支持重复读取优化、内容不变不新增版本、局部修改、资源维护、置顶、归档及版本恢复。

## 工作与界面

- 支持 `/plan` 和 `/goal`，展示持久化的步骤、验收依据和任务状态；计划确认后再开始执行。
- 单聊和群聊可以分别选择本机项目目录，后续命令使用对应目录。
- 改进文件附件、Bot 和群聊引用卡片以及相关交互。

## 升级说明

- 工作记录升级为 SQLite 增量存储，首次启动自动导入旧数据。`state.json` 保留为迁移输入，并在正常退出时导出兼容副本。
- 文件检查点默认关闭，可在“设置 → 运行”中开启。它覆盖文件工具的写入，不包含任意命令或桌面应用的全部修改；回滚不会覆盖任务之后的文件改动。
- 现有 Provider 默认沿用 OpenAI 兼容协议；使用原生协议时，在 Provider 配置中选择对应类型。

Windows 用户下载 `AelionBot-Setup-0.5.0-x64.exe` 安装；现有用户也可以通过“设置 → 关于 → 检查更新”升级。
