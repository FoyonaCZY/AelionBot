# AelionBot v0.23.2

`open_preview` 可以打开正在运行的网页。

- 伙伴可以预览工作电脑或本机上的本地开发服务器，以及普通 HTTP/HTTPS 网页。
- 本地网页需标明 `location: vm` 或 `host`。工作电脑上的服务会经现有 SSH 隧道转到本机回环地址。
- 预览使用隔离浏览器，不能下载或申请网站权限。反馈截图会带上当前网址（常见密钥参数会脱敏）。

## 下载

- Windows x64：`AelionBot-Setup-0.23.2-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.23.2-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.23.2-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
