# AelionBot v0.25.2

设计师增加网站复刻任务，并改进演示文稿版式。打开预览后从对话发送会带上当前画面，不再单独勾选。

## 网站复刻

- 新任务类型：按公开网页做本地视觉复刻，而不是另做一版通用落地页。
- 交付 HTML，并写 `NOTES.md`（来源网址、还原了什么、登录/支付等明确不克隆的部分）。
- 先阅读原站或用户截图，再用本机文件重建；不安装浏览器收割脚本。

## 演示文稿

- `design_deck` 增加目录（agenda）和收束（cta）版式，并保留封面、对比、时间线、数据页等。
- 一页一个重点；没有真实数据时用「—」，不编造数字。
- 已选设计系统时不再追问配色和字体。

## 其它

- HTML 发布会拦截远程字体和套话占位。
- 设计系统参考会带上 USAGE.md。
- 预览侧栏打开时，对话发送默认附上当前画面，去掉「附带画面」勾选。

## 下载

- Windows x64：`AelionBot-Setup-0.25.2-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.25.2-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.25.2-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
