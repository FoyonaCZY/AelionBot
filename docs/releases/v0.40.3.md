# AelionBot v0.40.3

这一版让启动更可靠：窗口会尽快出现，不会再因为页面加载慢而一直看不到，也不会再弹出“启动失败”。

## 简体中文

### 启动

- 窗口在界面画出第一帧时就显示，最多等 3 秒。以前要等整个页面加载完才显示，启动时如果界面忙，可能好几分钟都看不到窗口，只能在任务管理器里看到它在运行。
- 页面加载失败时会自动重试，不再弹出“AelionBot 启动失败 ERR_FAILED (-2)”并退出。
- 应用已经在运行时再双击图标，会把已有的窗口还原并放到最前面，窗口最小化或还在加载时也一样。
- 每次启动会在诊断记录里写下各阶段用时，以后反馈“启动慢”时可以直接看出慢在哪一步。

## English

### Startup

- The window appears with the first frame of the interface, after at most 3 seconds. It used to wait for the whole page to finish loading, so a busy start could leave no window for minutes while the app ran in Task Manager.
- A failed page load is retried instead of showing “AelionBot 启动失败 ERR_FAILED (-2)” and quitting.
- Launching the app again while it runs restores and focuses the existing window, also while it is minimized or still loading.
- Each launch writes how long every phase took to the diagnostic log, so a slow start can be traced to its step.
