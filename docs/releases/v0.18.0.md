# AelionBot v0.18.0

本版改善问答和任务文件的展示，提高长内容生成的默认输出额度，仅提供 Windows x64 安装包。

- 修复会话内问答直接显示原始 JSON 的问题，按问题与回答展示，并兼容已有问答记录。
- 默认单次输出上限提高到 65,536 tokens，移除主任务隐藏的 4,096 tokens 限制；实际额度受剩余上下文空间及用户配置约束。
- 主会话和群聊的多个任务文件默认收起为“文件 · N 个”，展开后可滚动查看、预览和保存；单个文件直接显示。
- 运行状态展示当前工具操作、模型请求、重试和等待情况，并提供最近完成步骤及停止入口。
- 改善源代码文件预览，支持更多语言的语法高亮。
- 工作电脑文件窗口新增目录树，可按目录浏览当前 Bot 的工作文件。

## 下载

- Windows x64：`AelionBot-Setup-0.18.0-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
