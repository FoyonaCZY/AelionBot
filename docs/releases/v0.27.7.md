# AelionBot v0.27.7

发出 v0.27.6 因 Windows 后台进程测试失败而没公开的内容：生图协议猜错时回退，并记住走通的通道。

## 生图

- 先按模型名猜测 Gemini `generateContent`、Responses 托管生图或 `/images/generations`。失败则试其余通道（Responses 只在 Provider 本身是 Responses 时才试）。
- 成功后按 Provider、Base URL 和模型名记下来，下次同一模型直接走记住的那条。

## 发布

- Windows 本机后台进程把就绪日志写到控制台并立刻 Flush；包装脚本在支持时打开 AutoFlush。测试等待加长，避免 CI 读到空输出。

## 下载

- Windows x64：`AelionBot-Setup-0.27.7-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.27.7-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.27.7-mac-x64.dmg` / `.zip`
