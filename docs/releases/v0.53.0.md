# AelionBot v0.53.0

## 简体中文

### 定时任务升级为“自动化”

- 除了按时间运行，自动化还可以在这些时候触发：
  - 有人调用它的 Webhook 地址
  - 本机某个文件夹里的文件有变化
  - 连接器收到消息，可以限定渠道和关键词
  - 另一个自动化结束，可以串成流程
  - 一段检查脚本判断该运行了
- **Webhook**：只在本机 `127.0.0.1` 监听，地址里带密钥，用 POST 调用。请求内容会作为触发信息交给 Bot。
- **检查脚本**：用 JavaScript 写，每隔几分钟在应用内的沙箱里运行一次，只能访问公网地址。返回 `{ fire: true }` 时触发；`state` 会保留到下一次检查。
- 非定时的触发会等会话空闲、并且距上次运行满 1 分钟后才执行，期间的多次触发合并成一次。触发信息作为外部数据交给 Bot，不会被当作新的指令。
- Bot 写的检查脚本创建后是暂停状态，你在面板里看过代码、点“看过了，启用”后才会运行。Bot 想监视本机文件夹时，要你批准。
- 已有的定时任务会自动迁移，照常运行。

### 回复里直接画图表和小组件

- Bot 不用再调用工具，直接在回复里写图表、表格、指标、时间线、提示框和计算器，流式输出时和正文一起出现。
- 新增 HTML 小组件，用来做卡面对比、示意图、小工具这类固定样式表达不了的内容。小组件在隔离的沙箱里运行，不能联网，也访问不到应用；会跟随深浅色主题，高度随内容变化。
- 小组件里的按钮可以把一句追问填进输入框，由你决定要不要发送。
- 飞书、企业微信、微信里收到的，以及朗读的，都是这些内容的文字版本。以前的回复照常显示。

### 语音输入和朗读

- 在“设置 → 模型”里给语音识别和语音合成各选一个服务。支持三种协议：
  - OpenAI 音频接口，适用于 OpenAI、硅基流动、Groq 等
  - 在对话接口里传音频，适用于小米 MiMo、通义 Qwen3-ASR
  - DeepSeek 的语音接口
- 输入框新增麦克风：录完后文字填进输入框，不会自动发送。
- 回复下方新增“朗读”，每个 Bot 可以设置自己的音色。
- 飞书里的语音消息会先转成文字再交给 Bot。打开“用语音回复 IM 里的语音消息”后，Bot 还会在飞书里回一条语音。
- 配置好语音服务后，Bot 也可以转写音频文件、把文字合成为音频。

### 其他

- DeepSeek 插件新增文字识别（OCR），可以识别图片、PDF、Word 和 PPT 里的文字。
- 生图协议不再提供“自动识别”，需要选一个具体的协议。已经自动识别出的协议会保留下来。
- 输入框 + 菜单里的“这段对话不记入记忆”已移除。不想被记住时，在消息里说“这次不要记”即可。

## English

### Scheduled tasks are now Automations

- Besides running on a schedule, an automation can start when:
  - its webhook address is called
  - files change in a folder on this computer
  - a connector receives a message, optionally from one channel or containing a keyword
  - another automation finishes, so you can chain them
  - a check script decides it's time
- **Webhooks** listen only on this computer at `127.0.0.1`. Each address includes a secret, and calls use POST. What you send is passed to the Bot as trigger details.
- **Check scripts** are JavaScript. They run every few minutes in a sandbox inside the app and can only reach public addresses. Returning `{ fire: true }` starts the automation, and `state` is kept for the next check.
- Triggers other than time wait until the conversation is free and at least a minute has passed since the last run. Triggers that arrive in the meantime are merged into one. Trigger details reach the Bot as outside data, never as new instructions.
- A check script written by a Bot starts paused. It runs only after you've read the code in the panel and clicked "Reviewed, turn on". If a Bot wants to watch a folder on this computer, it needs your approval.
- Existing scheduled tasks are migrated automatically and keep running.

### Charts and widgets right in replies

- Bots no longer call a tool for charts, tables, metrics, timelines, callouts and calculators. They write them straight into the reply, so these appear while the text streams.
- New HTML widgets cover what fixed formats can't, such as card comparisons, diagrams and small tools. Widgets run in an isolated sandbox with no network and no access to the app. They follow the light or dark theme and resize to fit their content.
- A button in a widget can put a follow-up question in the message box, and you decide whether to send it.
- Feishu, WeCom, WeChat and read-aloud get a text version of these. Earlier replies display as before.

### Voice input and read-aloud

- Pick a service for speech recognition and one for speech synthesis under Settings → Models. Three protocols are supported:
  - OpenAI's audio API, for OpenAI, SiliconFlow, Groq and others
  - audio in the chat API, for Xiaomi MiMo and Qwen3-ASR
  - DeepSeek's speech API
- A new microphone in the message box puts what you said into the box without sending it.
- Replies have a new Read aloud button, and each Bot can have its own voice.
- Feishu voice messages are turned into text before they reach the Bot. Turn on "Reply to IM voice messages with voice" and the Bot also answers with a voice message in Feishu.
- Once speech is set up, Bots can also transcribe audio files and turn text into audio.

### Other changes

- The DeepSeek plugin adds OCR, which reads text in images, PDFs, Word documents and PowerPoint files.
- The image generation protocol no longer offers automatic detection; choose a specific protocol. Protocols that were already detected are kept.
- "Don't remember this conversation" has been removed from the + menu in the message box. To keep something out of memory, say "don't remember this" in your message.
