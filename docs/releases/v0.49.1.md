# AelionBot v0.49.1

## 简体中文

### 处理过程

- 展开后的步骤改用统一的灰色线条图标，不再是一列彩色方块；只有失败的步骤显示红色、进行中的步骤显示紫色进度圈。思考行的字更淡、行更矮，命令和文件操作更醒目。

### 消息排版

- 代码块改为带细边框的卡片：标题栏显示终端或代码图标和语言名，复制按钮带图标，复制后显示绿色对勾；超过 24 行的代码默认折叠，可点击“展开全部”。
- 表格改为同样的卡片：表头颜色更淡，鼠标所在行会高亮，保留 Markdown 里设置的对齐方式。
- 引用改为带紫色左边的浅色底，分隔线两端渐隐，行内代码加了细边框。

### 工作电脑

- 重新设计电脑关闭时的卡片：卡片本身就是屏幕，浅色主题下是淡紫色、深色主题下是深色；Bot 在柔和的光晕里打瞌睡，旁边飘着几个 z。启动中显示进度，出错时光晕和提示变为红色。

## English

### Run steps

- Opened steps use one set of grey line icons instead of a column of coloured tiles; only a failed step turns red and a running step shows a purple spinner. Thought rows are lighter and shorter, so commands and file operations stand out.

### Message formatting

- Code blocks are a card with a fine outline: the header shows a terminal or code mark with the language, copy has an icon and turns into a green tick once copied, and code longer than 24 lines folds until you choose "show all".
- Tables are the same card, with a quieter header row, a highlight on the row under the pointer and the column alignment set in the Markdown.
- Quotes have a light background with a purple edge, rules fade out at the ends and inline code has a fine outline.

### Work computer

- Redesigned the card shown while the computer is off: the card is the screen itself, pale lilac in the light theme and dark in the dark theme, with the Bot dozing in a soft glow as a few z's drift up. Starting shows its progress there, and an error turns the glow and the status red.
