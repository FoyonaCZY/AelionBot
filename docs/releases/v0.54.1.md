# AelionBot v0.54.1

## 简体中文

### 手机端改版

- 首页最上面显示正在用的电脑和连接状态，同一网络直连时会标出来。每个 Bot 下面列出它今天的工作会话，正在做的事和已经做了多久都能直接看到；等你批准的请求改成更紧凑的卡片。
- 对话页标题显示 Bot 和当前会话，点一下可以切换会话。消息按日期分隔，最新回答下面有复制、朗读、引用和更多操作；Bot 工作时，输入框上方显示当前步骤和停止按钮；往上翻得远了，会出现“到最新”的按钮。
- 新建会话时先是空白页，发出第一条消息时才真正创建，会话名取自这条消息。
- 设置里新增“外观”：跟随系统、浅色、深色。
- 某个页面出错时，会显示错误内容和“回到首页”按钮，不会再是一片空白。
- 首页把 Bot 的主聊天和工作会话分开显示，需要电脑端也更新到这个版本；电脑端没更新时，首页按原来的方式显示。

### 问题修复

- 修复部分安卓手机打开工作电脑时一直黑屏的问题。
- 修复聊天停靠在预览旁边时，输入框透明、能看到下面消息的问题。
- DeepSeek 偶尔会把工具调用当成普通文字返回，回复里会出现一串 `DSML` 标记，任务也随之停下。现在这类调用会被识别并照常执行，输出过程中也不会显示这些标记。Qwen、GLM 用文字写出的工具调用以前只会被删掉，现在也会执行（使用 OpenAI 兼容协议时）。

## English

### Redesigned phone app

- Home shows the computer in use and its connection on top, including when the phone is connected directly on the same network. Each Bot lists its work sessions of today underneath, with what they are doing and for how long; approvals waiting for you are compact cards.
- The chat title shows the Bot and the session; tap it to switch sessions. Messages are separated by day, and the latest answer has copy, read aloud, quote and more under it. While a Bot works, the step it is on and a stop button sit above the composer; after scrolling up a long way, a button jumps back to the latest.
- A new session opens empty and is created with the first message, named after it.
- Settings has a new Appearance option: System, Light or Dark.
- A screen that fails shows the error and a way back home instead of a blank page.
- Home shows a Bot's main chat apart from its work sessions once the desktop runs this version; with an older desktop, home looks as before.

### Fixes

- Fixed the work computer staying black on some Android phones.
- Fixed the composer being see-through when the chat is docked beside a preview.
- DeepSeek sometimes returned a tool call as plain text: a string of `DSML` markup appeared in the reply and the task stopped. These calls are now recognized and run, and the markup is not shown while the reply streams. Tool calls Qwen and GLM write as text were only removed before; they now run too (with OpenAI-compatible providers).
