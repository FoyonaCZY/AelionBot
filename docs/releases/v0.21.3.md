# AelionBot v0.21.3

工作电脑存储上限与空间回收的小版本。

- 电脑设置可指定工作电脑占用上限（默认 12 GiB，范围 8–256 GiB）。接近上限会预留缓冲并暂停，不删除文件。
- 可手动回收未使用的镜像空间；默认在应用更新后安全停机时也会尝试回收。旧电脑会在下次离线启动时补做。
- 安装软件成功后会清理可再下载的安装缓存，日常维护会限制系统日志体积。

## 下载

- Windows x64：`AelionBot-Setup-0.21.3-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.21.3-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.21.3-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
