# AelionBot v0.39.1

## 简体中文

### 文件改动显示 diff

- 「修改文件」和「应用补丁」步骤展开后显示具体改动：删除的行标红、新增的行标绿，并保留几行上下文；改动较长时先折叠，可以展开全部。
- 一次补丁改了多个文件时，每个文件单独列出，并标明新文件、已删除或重命名。
- 步骤收起时也能看到新增和删除的行数。
- 改动只用于显示，不会发回给模型；内容和工具记录一样经过脱敏。之前的步骤没有保存改动内容，仍按原来的样子显示。

### 修复

- Windows 和 Linux 上，对话顶栏右侧的按钮不再被窗口的最小化、最大化、关闭按钮挡住。

## English

### Diffs for file edits

- Expanding an "Edit file" or "Apply patch" step shows what changed: removed lines in red, added lines in green, with a few lines of context. Long changes fold until you expand them.
- A patch that touches several files lists each file on its own, marked as new, deleted or renamed.
- A folded step shows how many lines were added and removed.
- The diff is for display only and is never sent back to the model; it is redacted like the rest of the tool record. Earlier steps did not keep their changes and look as before.

### Fixes

- On Windows and Linux, the buttons at the right of the conversation header are no longer covered by the window's minimize, maximize and close buttons.
