# AelionBot v0.22.0

插件管理、用 @ 引用本机文件，以及本地视频抽帧。

## 插件

技能和 MCP 集中在插件页管理：搜索、分类、开关，以及添加技能目录或导入 MCP 配置。不会覆盖你自己添加的技能。

## 文件引用

在主会话或群聊输入 `@`，除伙伴外还可以选择当前工作目录里的文件。插入的是本机路径引用，不会把原文件再复制一份；之后仍按现有本机权限读取。

## 视频理解

新增 `video_frames`：从本机路径或已收到的附件抽帧，生成带时间戳的拼图给模型看。默认抽 12 帧，可指定时间范围。只覆盖抽到的画面，不包含音频或转写。解码在本地完成，不上传到额外解析服务。
