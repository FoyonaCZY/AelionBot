# AelionBot v0.15.0

本版优化长任务上下文与缓存复用，修复计划更新反复重试的问题，仅提供 Windows x64 安装包。

- 保持已发送的上下文顺序，任务状态和记忆、技能更新以新增事件通知；主会话、Bot 私聊和群聊使用统一的上下文管理。
- 修复 token 估算倍率重复放大且无法回落的问题；使用实际用量估算新增内容，减少过早压缩和零碎裁剪。
- 持久保存裁剪视图与参考快照，重启或继续任务后不再反复展开、重组旧历史。
- 图像改为批量归档，新增截图不会立即移除旧图；重新读取已归档附件时正常显示。
- Responses 新增自动、HTTP 和 WebSocket 连接方式；支持严格前缀校验后的增量传输，以及连接失效时的完整请求回退。
- 缓存诊断新增上下文变化原因、实际传输方式和成功请求前缀复用信息。
- 修复过期计划更新导致 Bot 反复寻找执行证据的问题；执行记录支持精简分页查询，真实操作失败仍需核验。

## 下载

- Windows x64：`AelionBot-Setup-0.15.0-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
