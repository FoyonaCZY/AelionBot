# AelionBot v0.32.0

## 简体中文

### 1. SOUL.md

- Bot 的「职责描述」换成 SOUL.md：用 Markdown 定义 Bot 的人格、语气、价值观和边界，可以直接粘贴或导入在 OpenClaw、Hermes 等 Agent 里用过的文件。
- 与 Hermes 一样，SOUL 原样放在系统提示最前面，YAML frontmatter 会被去掉。其后是应用的身份绑定：Bot 名称、本应用实际提供的工具和后续规则优先于 SOUL，SOUL 不授予权限。
- 最多保存 20,000 字符。注入长度随模型上下文窗口缩放（32k 窗口约 8,000 字符，最少 4,000）；超出时保留开头 70% 和结尾 20%。保存时去掉可用于隐藏文字的零宽字符和双向控制字符。
- 编辑框支持导入 .md / .txt 文件并显示字数。新建 Bot 时可从示例开始：后端工程师、数据分析师、写作编辑、调研助手；设计师 Bot 为产品设计师。示例提供简体、繁体和英文三个版本。
- 已有 Bot 的职责原文迁移为 SOUL，内容不变；只有应用自动生成的默认职责会换成新的默认 SOUL。群聊成员列表、@ 提及和 `bots_list` 显示 SOUL 摘要。

### 2. 群聊

- 实验功能：群聊设置中可以一键下载并启用本地 Laya 模型，由它为每个 Bot 判断「旁听」或「参与」，参与时才启动主模型。默认关闭，不下载也不启动进程；Laya 不可用时回退主模型判断。支持 Apple 芯片 Mac、Windows x64 和 Linux，Intel Mac 暂不支持。详见 `docs/laya-local.md`。
- 群任务列表过长时在列表内滚动，折叠标题和「继续」按钮始终可见。
- 认领、更新群任务和更新计划不再被误判为没有进展。

### 3. 模型

- Claude 的推理强度设置现在会实际发送：Claude 4.6 及以上使用自适应思考，4.7 及以上不再发送会被拒绝的固定思考预算。Anthropic Provider 的设置里显示推理强度选项。
- 保存和请求时自动整理 Base URL：去掉多余空格和斜杠、补全协议，去掉误粘贴的 `/v1/messages`、`/chat/completions` 等接口后缀；Anthropic 地址缺少版本时补 `/v1`。网关返回 HTML 页面时直接提示检查 Base URL，不再按不完整的流反复重试。

### 4. 其他

- 新建 Bot 后保持选中新 Bot，不会跳回最早的 Bot。

## English

### 1. SOUL.md

- A Bot's role description is replaced by SOUL.md: Markdown that defines its personality, tone, values and boundaries. Paste or import a file you already use in OpenClaw, Hermes or another agent.
- As in Hermes, the soul leads the system prompt verbatim, with YAML front matter removed. The app's identity binding follows it: the Bot name, the tools this app actually provides and later rules take precedence, and the soul grants no permissions.
- Up to 20,000 characters are stored. The injected length scales with the model's context window (about 8,000 characters for 32k, at least 4,000); oversized souls keep the first 70% and last 20%. Zero-width and bidirectional control characters that can hide text are removed on save.
- The editor imports .md / .txt files and shows a character count. New Bots can start from an example: backend engineer, data analyst, writing editor or research assistant, and product designer for designer Bots, each in Simplified Chinese, Traditional Chinese and English.
- Existing role text becomes the soul unchanged; only the app's own generated default roles are replaced by the new default soul. Group member lists, @ mentions and `bots_list` show a summary of the soul.

### 2. Group chats

- Experimental: group chat settings can download and enable a local Laya model that decides for each Bot whether to listen or take part, starting the main model only to take part. It is off by default, downloads and starts nothing until enabled, and falls back to the main model when unavailable. Supported on Apple silicon Macs, Windows x64 and Linux; Intel Macs are not supported yet. See `docs/laya-local.md`.
- A long group task list scrolls within itself, so its header and Continue buttons stay visible.
- Claiming or updating a group task and updating a plan no longer count as making no progress.

### 3. Models

- Claude's reasoning effort setting is now actually sent: Claude 4.6 and later use adaptive thinking, and 4.7 and later no longer get a fixed thinking budget they reject. Anthropic providers show the reasoning effort setting.
- Base URLs are cleaned up when saved and when requests are built: extra whitespace and slashes are removed, a missing scheme is added, and pasted endpoint suffixes such as `/v1/messages` or `/chat/completions` are stripped. Anthropic URLs without a version get `/v1`. A gateway's HTML page now fails once with a Base URL hint instead of being retried as an incomplete stream.

### 4. Other

- A newly created Bot stays selected instead of jumping back to the oldest Bot.
