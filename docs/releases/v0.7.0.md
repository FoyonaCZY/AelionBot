# AelionBot v0.7.0

新增 Bot 本机权限模式，修复任务被表情提前结束的问题，并更新定时任务与下拉选择界面。

## 本机权限模式

- 在 Bot 主会话输入框底部选择“每次询问”“自动审批”或“完全访问”，按 Bot 保存。
- 自动审批通过本地规则放行工作目录内普通文件的读取、创建和编辑，不为每次代码修改调用审核模型。敏感配置、越界操作及未匹配的命令交给应用默认模型审核。
- 模型审核未放行或无法完成时，在会话内显示理由，等待用户确认。切换权限模式、取消任务或更换默认模型后，过期审核结果不能放行操作。
- 群聊没有独立权限设置，从群聊接下的任务跟随执行 Bot 的主会话权限。

## 任务执行修复

- 修复添加 emoji 后直接结束整个任务的问题；表情与工作工具混用时会继续执行，并保留进度说明和最终答复。
- 修复群聊中已发送表情后，最终文字结果被忽略的问题。

## 定时任务与选择框

- 更新右侧定时任务列表、状态筛选、空状态和暂停／恢复入口。
- 重新整理任务编辑窗口的内容、时间设置、下次执行预览、状态和操作按钮；保留立即运行及删除确认。
- 统一模型、Provider、技能范围、任务频率及状态等下拉选择框的样式和键盘交互。
- 任务时区支持搜索选择和直接输入，弹出列表会适应窗口可用空间。
- 新建 Provider 默认选择 OpenAI Responses；已有 Provider 的协议保持原配置。

## 下载与更新

- Windows x64：下载 `AelionBot-Setup-0.7.0-x64.exe`，或在客户端检查更新。
- Mac：按芯片选择 `mac-arm64`（Apple Silicon）或 `mac-x64`（Intel）的 DMG／ZIP，需要 macOS 15 或更高版本。
- Mac 继续以预览版提供。未配置正式签名和公证的构建需手动下载替换；首次打开方式见 [Mac 预览版说明](https://github.com/FoyonaCZY/AelionBot/blob/v0.7.0/docs/releases/v0.6.0.md)。无需关闭系统安全保护。
- Release 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
