# AelionBot v0.14.2

本版进一步优化请求缓存稳定性和诊断，仅提供 Windows x64 安装包。

- 创建普通计划、处理重复表情和首次读取大输出时保持工具定义稳定，临时限制由执行前校验处理。
- 统一工具名称和结构排序，消除注册顺序或对象键顺序造成的请求变化。
- 模型请求使用独立快照，重试不受调用方后续修改影响；增加稳定的会话路由标识。
- Anthropic 缓存断点对齐完整工具调用，保留原生推理内容和签名。
- 开场白单独统计，保留其原生推理供后续对话使用。
- 诊断新增工具变化明细、底层连接错误码，并修复超长输入变化被误判为相同的问题。
