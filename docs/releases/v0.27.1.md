# AelionBot v0.27.1

补上画布和预览叠在一起的问题，并让 Bot 可以单独配置生图模型。

## 设计师

- 空画布是一张白页，不再放标题、任务原文和米色示意框。
- 画布和普通网页预览用同一块表面铺满，点成果只在画布里换文件，不再另开一张带设备框的大预览。
- 打开设置等弹窗时会先藏掉原生网页层，不再盖住对话框。
- 网页预览层停在工具栏下面，顶栏和地址栏不必靠任务下拉才能看见。

## 生图

- Bot 资料可单独选择生图模型。配置后对话里出现 `generate_image`，设计师的 `design_image` 也会优先用它。
- Responses 走托管图片生成；其他协议走 OpenAI 兼容的 `/images/generations`。未配置的 Bot 行为不变。
