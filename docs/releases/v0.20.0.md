# AelionBot v0.20.0

本版恢复 Windows 与 macOS 全平台安装包，加快 Mac 发布构建，并补齐工作电脑办公环境。

## 平台

- Windows x64：安装包与自动更新。
- macOS 15+ Apple Silicon（ARM64）与 Intel（x64）：DMG、ZIP。当前 Mac 包如未配置公证，首次打开可能需在“系统设置 → 隐私与安全性”中选择“仍要打开”；检查更新后请下载新包替换应用。

GitHub 托管 Mac 没有嵌套虚拟化，发布工作流不再在 TCG 里安装 Linux 桌面。Mac 任务与 Windows 一样做源码检查、测试、打包和安装包校验。

## 工作电脑

- 预装压缩工具、LibreOffice Impress、表格/PDF 脚本库、Liberation 字体和拼音输入法。
- 桌面和 `open_app` 可打开演示文稿；聊天可预览 Excel 类表格文件。
- 已有工作电脑若软件版本落后，会弹出与首次设置相同的准备窗口，文件保留；也可稍后在电脑设置中更新。

## 其他

- 用户拒绝本机操作后，任务会带着拒绝结果继续，不再把拒绝当成整次运行失败。
- 带引号的检索参数可以写入命令授权规则。
- 补全电脑操作、权限拒绝和准备窗口相关翻译。

## 下载

- Windows x64：`AelionBot-Setup-0.20.0-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.20.0-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.20.0-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
