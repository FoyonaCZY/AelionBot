# AelionBot v0.33.0

## 简体中文

### 处理过程

- 思考、进度说明和工具调用现在按实际发生的顺序排在同一条时间线上，不再被拆成分散的消息或单独的「本轮操作」框。
- 任务结束后，最终回复之前的内容自动收起为一行「已处理 X · N 个步骤」，点击可展开；工具步骤可再点开查看输入和输出。
- 任务进行中只显示最近 3 步，更早的步骤收起；失败和正在执行的步骤有单独标记。

### 聊天记录搜索

- Bot 单聊的标题栏新增搜索框，也可按 Ctrl/Cmd+F 打开。支持多个关键词同时匹配，Enter / Shift+Enter 在结果间切换，Esc 关闭。
- 命中已收起的处理过程时会自动展开，并滚动到对应位置高亮。搜索范围是你和 Bot 的可读正文，不包括工具输出和思考内容。

### 修复

- 英文和繁体中文界面中，部分页面仍显示简体中文的问题。

## English

### Run process

- Reasoning, progress notes and tool calls now appear on one timeline in the order they happened, instead of being split into separate messages or a standalone "this run" box.
- When a task finishes, everything before the final reply collapses into a single "Processed X · N steps" line that can be expanded; each tool step can be opened to show its input and output.
- While a task runs, only the latest 3 steps are shown and earlier ones are collapsed; failed and running steps are marked.

### Chat search

- Bot conversations get a search box in the header, also opened with Ctrl/Cmd+F. Multiple terms must all match; Enter / Shift+Enter move between results and Esc closes it.
- A match inside a collapsed run expands it, scrolls to the message and highlights it. Search covers the readable text from you and the Bot, not tool output or reasoning.

### Fixes

- Some screens still showed Simplified Chinese in the English and Traditional Chinese interfaces.
