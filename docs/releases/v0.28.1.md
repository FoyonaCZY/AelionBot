# AelionBot v0.28.1

重新设计模型与 Provider 管理页，精简界面文案。

## 界面

- 模型设置分为“模型分配”和“Providers”。Provider 使用列表与配置双栏布局，连接、模型、生图和高级设置分别显示，保存按钮固定在底部。
- 模型搜索与新增入口固定在目录顶部，长列表单独滚动。支持窄窗口和深色主题。
- 设计工作区合并文件操作与输入区域，移除无文件时的成果栏；检查未通过时显示问题并禁用确认。
- 清理设置、Bot 资料、插件、任务进度、空状态及官网中的重复说明和冗余副标题，同步更新多语言文案。

## 修复

- 保存 Provider 期间切换到其他项，保存完成后不再跳回旧项或清空当前草稿。
- 隐藏分区中的参数未通过校验时，自动打开对应分区并定位字段。

## 下载

- Windows x64：`AelionBot-Setup-0.28.1-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.28.1-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.28.1-mac-x64.dmg` / `.zip`
