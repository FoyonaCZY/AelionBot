# AelionBot v0.19.0

本版新增界面语言切换和预览内文本编辑，仅提供 Windows x64 安装包。

- 界面支持简体中文、繁體中文和 English，可在“设置 → 外观 → 界面语言”切换，选择会保存在本机。
- 文件预览新增代码编辑器，可编辑支持的文本和源代码文件。
- 工作电脑文件支持保存修改，并检查文件版本，避免覆盖外部更新；附件可编辑后另存为副本。
- 关闭预览或应用时提示处理未保存的修改，保存期间阻止关闭，避免编辑内容意外丢失。

## 下载

- Windows x64：`AelionBot-Setup-0.19.0-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
