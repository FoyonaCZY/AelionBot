# AelionBot v0.20.1

官网下载与工作电脑打开文稿的小版本。

- 官网下载按访客系统和芯片推荐 Windows、Mac Apple 芯片或 Mac Intel 安装包，并提供其他版本链接。手机和 Linux 会提示查看全部版本。
- 工作电脑环境升级到 v6。已有电脑会提示更新，文件保留。
- `open_app` 可直接打开工作区内的 Writer、Calc、Impress 或文本文件，不必先开空白窗口再找文件。
- 工作电脑命令说明标明工作目录是当前 Bot 目录。

## 下载

- Windows x64：`AelionBot-Setup-0.20.1-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.20.1-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.20.1-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
