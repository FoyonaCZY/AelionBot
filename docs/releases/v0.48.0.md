# AelionBot v0.48.0

## 简体中文

### 界面

- 应用外壳统一为磨砂玻璃和悬浮卡片：主屏、插件页、聊天/画布预览与设置弹窗共用环境色、圆角和阴影；聊天页顶部改为左上角的短悬浮条。
- 画布与预览切换加入布局过渡：对话栏收拢、画布从中心展开；主屏左右卡片保持同高。
- 插件页和设置页压平嵌套卡片，搜索框、composer、工作目录和权限选择统一为磨砂表面；设置中的选择框恢复原生箭头和平面填充。
- 修复侧栏品牌位置、会话悬浮、上下文圆环居中，以及画布和设置页里重复身份、底色不一致等问题。

### 预览

- 支持 MP4、M4V、MOV、WebM 和 OGV 视频内嵌预览，带原生播放控制；补充 `media-src` 内容安全策略。

### 开发与窗口

- dev 构建可以和已安装的稳定版同时运行：源码开发、`AELION_DEV=1`、`--dev` 或 macOS 非 `/Applications` 路径不再抢单实例锁，稳定版仍保留锁。
- 双击窗口顶部空白可以最大化/还原，不再选中文字；展开态预览会关闭顶部拦截层。

## English

### Interface

- Unified the app shell around frosted glass and floating cards: the main view, plugins page, chat/canvas preview and settings dialog now share the ambient background, radii and shadows; the chat header is a short floating bar at the top-left.
- Added a layout transition between chat and preview: the conversation column narrows and the canvas expands from the centre, while the main-screen cards keep the same height.
- Flattened nested cards on the plugins and settings pages; search fields, the composer, workspace and permission pickers use one frosted surface, and settings selects keep the native arrow and a flat fill.
- Fixed the sidebar brand position, session hover treatment, context-ring centering, duplicate identities and inconsistent surfaces in the canvas and settings views.

### Preview

- Added inline video previews for MP4, M4V, MOV, WebM and OGV with native playback controls, plus the required `media-src` content-security policy.

### Development and window

- Dev builds can run beside the installed stable app: source runs, `AELION_DEV=1`, `--dev`, and macOS builds outside `/Applications` no longer take the single-instance lock; the stable app keeps it.
- Double-clicking the empty top edge toggles maximize/restore without selecting text; an expanded preview hides that top strip.
