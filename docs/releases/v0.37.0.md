# AelionBot v0.37.0

## 简体中文

### 群聊协作

- 谁来回应改成按规则判断：被 @、有人回复自己的消息、自己的定时或设计任务会唤醒对应 Bot；消息点名了别人时，其他成员先等被点名的回答（最多 20 秒）；其余情况由 Laya 针对每条消息判断一次是否相关。
- 用户发到群里、没有点名的消息，所有空闲成员都会回应，别人已经说过的可以只用表情回应；正在忙的成员只在消息和自己的角色或手头工作有关时才接话。
- Bot 之间互相唤醒有上限：同一对 Bot 自用户上次发言后来回两轮就停下，由先发言的一方总结；所有 Bot 之间的消息累计十条后暂停，等用户再发言。
- Bot 的最终回复都会发到群里；不想说话时直接不输出内容，不再需要静默标记。
- 没人回应用户消息时，只在该消息下方显示一行提示，不再发一条系统消息。
- 群聊输入框的停止按钮现在会停止整轮讨论，停止后会显示原因和「继续」按钮。退出应用不再算作停止：没做完的工作标记为中断，「继续本轮讨论」会接着原来的成员、运行和计划往下做。
- 去掉了群任务，多步工作改用计划；群聊表情工具改名为 group_react。

### 设计师

- 修复在画布上打开字体弹窗时，弹窗先被挡住、画布变白后才出现的问题。
- 预览顶栏的颜色跟随应用的浅色或深色，布局更简洁：本地文件不再显示重复的地址栏，按钮统一改成透明底，导出按钮不再是白色胶囊。

### 狼人杀

- 对局开始后才加入群的 Bot 会自动入座，离开群的 Bot 会让出座位。
- 还没人出局就中途结束的对局显示为「对局已中止」，不计胜负。
- 看过的战报卡片不再一直停在聊天底部，大厅里保留「上一局 · 查看战报」入口。
- 每个群只保留最近一局的记录，旧对局不再重复写入磁盘。

## English

### Group collaboration

- Who responds now follows explicit rules. An @ mention, a reply to the Bot's own message, or one of its scheduled or design tasks wakes that Bot. When a message addresses someone else, the other members wait for that member to answer first (up to 20 s). Anything else gets one relevance check from Laya per message.
- A user message sent to the whole group with no one addressed gets an answer from every idle member; a reaction is enough when others have already said it. Busy members only reply when the message concerns their role or current work.
- Bot-to-Bot wakes are capped. Two Bots stop after two rounds since the user last spoke, and the one who spoke first sums up. All Bot-to-Bot wakes pause after ten such messages until the user speaks again.
- Every final reply from a Bot is posted to the group. To stay quiet, a Bot ends with no text; the silence marker is no longer needed.
- When nobody answers a user message, a quiet hint appears under it instead of a system message.
- The group composer's stop button now stops the whole round, and a stopped round shows the reason with a Continue button. Quitting the app no longer counts as stopping: unfinished work is marked interrupted, and "Continue this round" resumes it with the same member, run and plan.
- Group tasks have been removed; multi-step work uses plans. The group reaction tool is now called group_react.

### Designer

- Fixed the font dialog on the canvas being covered at first, then the canvas turning white before the dialog appeared.
- The preview header follows the app's light or dark theme and has a simpler layout: local files no longer show a duplicate address bar, buttons have transparent backgrounds, and Export is no longer a white pill.

### Werewolf

- Bots that join the group after setup take free seats automatically, and Bots that leave give up theirs.
- A match ended before anyone was eliminated shows as "Game ended early" with no result.
- The report card no longer stays at the bottom of the chat once viewed; the lobby keeps a "Last game" entry to view the report.
- Each group keeps only its latest match, so older matches are no longer rewritten to disk.
