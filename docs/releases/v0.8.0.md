# AelionBot v0.8.0

本版改进 Bot 分析和修改项目的基础工具，修复本机文件批量读取失败及命令长输出卡顿，仅提供 Windows x64 安装包。

## 文件查找与读取

- 修复批量读取工具遗漏本机文件读取的问题；独立步骤并行执行，错误明确指出工具、参数或依赖，失败依赖的后续步骤会跳过。
- 增加本机文件路径查找和内容搜索，支持 glob、正则、上下文、忽略规则及分页，可在批处理中使用。
- 本机与工作电脑的文本文件支持按行或按字符范围读取，返回继续读取的位置、截断信息及文件版本；批处理子步骤的完整结果也可继续读取。
- 搜索在独立线程中执行，限制扫描量和时间，避免复杂检索阻塞界面。

## 精确修改与执行结果

- 增加本机和工作电脑文件的局部原文替换，默认要求唯一匹配，并核对读取时的文件版本，避免覆盖其他改动。
- 修改保留原文件的 BOM、换行格式和文件权限，沿用现有会话权限及文件检查点。
- 常规项目操作继续按会话权限规则处理；批量读取不会绕过审批，拒绝后停止本批请求。
- 本机命令分别保留标准输出与错误输出的首尾，提供实际退出码和省略量，避免大量输出遮住最后的报错。
- 修复长连续文本导致脱敏处理卡顿，以及后台日志分页拆坏中文或 emoji 的问题。
- 执行记录显示完整文件名及读取起始行，修复长路径导致文件名被提前截断的问题。

## 聊天链接

- 聊天中的网页链接可以在系统默认浏览器打开，包括 Markdown 链接、网址和表格中的链接；Bot 提及与脚注保留原有交互。

## 下载

- Windows x64：`AelionBot-Setup-0.8.0-x64.exe`，也可在客户端检查更新。
- 附带 `latest.yml`、差分更新文件和 `SHA256SUMS.txt`。
- 工作电脑的代理和联网配置保持不变。
