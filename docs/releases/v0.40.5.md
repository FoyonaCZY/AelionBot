# AelionBot v0.40.5

这一版让 Bot 在私聊里能想起自己在群里做过的事。

## 简体中文

### 私聊能找回群里的工作

- 在私聊里问 Bot“你在某个群里做了什么”，它可以检索到自己在各个群里的工作记录：它的发言、执行过的步骤和工具结果。结果会注明来自哪个群。
- 这些记录只在需要时检索，不会自动塞进私聊上下文；也只包括这个 Bot 自己的工作，看不到其他 Bot 的私有记录。
- 阅读某条记录的前后文时，只会显示同一个群里的相邻内容，不会和私聊记录混在一起。

## English

### Private chats can recall group work

- Ask a Bot in its private chat what it did in a group, and it can now find its own work records from each group: its replies, the steps it ran and their results, labelled with the group they came from.
- These records are searched on demand, never loaded into the private conversation by themselves, and cover only this Bot's own work, never another Bot's private records.
- Reading around a record shows its neighbours from the same group only, not mixed with the private chat.
