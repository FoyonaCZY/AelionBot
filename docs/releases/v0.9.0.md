# AelionBot v0.9.0

本版新增用量统计页，改进自动审批交互，支持 Bot 独立推理强度和自定义模型名，并优化聊天中的代码与 Markdown 显示。仅提供 Windows x64 安装包。

## 用量统计

- 「设置 → 用量」提供时间趋势图、Provider 与模型分布图及明细表，支持按日期、Provider、模型和请求用途组合筛选。
- 支持最近 1/7/30/90 天和自定义日期，按小时、天或月查看；图表可以悬停、使用键盘查看，也可点击分布图继续筛选。
- 展示输入、输出、缓存读取、缓存写入、推理 token 和缓存命中率，使用完整的已保存请求历史。
- 区分真实的零用量和服务未返回的数据；缺少完整用量的请求单独标记。流式累计值和部分更新不会重复相加。

## 自动审批

- 默认模型审核期间不再显示权限卡片或通知，可以继续操作其他页面。
- 模型明确允许则继续，明确拒绝则停止；无法判断、审核失败或超时才显示会话内确认请求。
- 取消任务或改变权限模式后，过期的审核结果不会继续执行操作。

## Bot 模型配置

- 推理强度由每个 Bot 独立保存，使用默认模型时也可以分别设置。
- 模型名和推理强度均可直接输入自定义值，也能从已有模型和常用推理值中选择。
- 新建 Bot 时即可指定模型和推理强度；清空推理强度表示使用模型服务默认值。
- 旧 Provider 推理配置会迁移到相应 Bot 和默认模型，并保留迁移备份。

## 聊天显示

- 代码块增加语言标记、语法高亮和复制按钮，保留原始缩进与换行。
- 改进正文、标题、列表、引用、链接、表格和行内代码的显示，群聊同步使用统一的 Markdown 样式。

## 下载

- Windows x64：`AelionBot-Setup-0.9.0-x64.exe`，也可在客户端检查更新。
- 附带 `latest.yml`、差分更新文件和 `SHA256SUMS.txt`。
- 工作电脑的代理和联网配置保持不变。
