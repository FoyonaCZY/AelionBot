# AelionBot v0.29.2

## 简体中文

### 画布与导出

- 设计画布统一使用“导出”入口，支持 Sketch、PDF、PNG、SVG、独立 HTML 和项目 ZIP。
- Sketch 文件包含“保真图层”和“可编辑文字”两套画板。本地字体尽量转换为矢量轮廓，复杂效果使用局部图片保留，每个画板附带隐藏的原画面参考层。
- 导出前处理未保存的修改；取消或生成失败不会覆盖已有文件。

### 文件预览

- 普通文件预览改为“打开”菜单，支持默认应用、选择其他应用、打开所在文件夹和另存为。Windows 使用系统应用选择器。
- 本机文件优先打开原路径；没有可用原路径的附件和工作电脑文件会准备本机副本。
- 统一预览工具栏和提问区域的浅色配色，修复上下工具栏色差；支持窄窗口和键盘操作。

### 设计师字体

- 设计师 Bot 可根据任务自行搜索、下载并使用开源字体，无需让用户逐项操作字体面板。
- 字体文件和授权记录保留在项目中，缓存后可离线复用。

### 群聊协作与修复

- 群成员独立接收公开消息、认领任务并汇报进展；忙碌期间的新消息排队处理，已提交的发言重试不会重复投递。
- 群任务绑定实际收到的用户请求，避免把加入通知、其他任务或未收到的消息当作任务来源。
- 加强私聊与群聊历史隔离，修复迁移后的群记录进入私聊搜索、私聊读取群消息以及群任务预览范围不正确的问题。

### 使用说明

Sketch 转换优先保留外观，复杂区域可能是图片；“可编辑文字”画板需要接收端安装对应字体。网页响应式规则和交互不会转换为 Sketch 原生行为。本版通过了官方文件结构校验和内部视觉比对，尚未完成 Sketch/Figma 客户端的实际导入验收。

## English

### Canvas and export

- A single Export menu in the design canvas now supports Sketch, PDF, PNG, SVG, standalone HTML, and project ZIP.
- Sketch files include two artboards: appearance-preserving layers and editable text. Local fonts are converted to vector outlines where possible, complex effects are retained as image regions, and each artboard includes a hidden reference screenshot.
- Unsaved changes are handled before export. Cancelling or failing to generate a file leaves existing files intact.

### File previews

- Regular file previews now have an Open menu with Default app, Choose another app, Show in folder, and Save as. Windows uses the system application chooser.
- Local files open from their original location when available. Attachments and workspace-computer files without an available local original are prepared as local copies.
- Preview toolbars and the question input area use a consistent light palette. The menu supports narrow windows and keyboard navigation.

### Designer fonts

- Designer Bots can search for, download, and use open-source fonts as needed for a task without asking the user to operate the font panel.
- Font files and license records remain in the project, with cached fonts available for offline reuse.

### Group collaboration and fixes

- Group members independently receive public messages, claim tasks, and report progress. Messages arriving while a Bot is busy are queued, and retries do not duplicate committed messages.
- Group tasks are tied to user requests the Bot has actually received, preventing join notifications, unrelated tasks, or unseen messages from becoming task sources.
- Improved isolation between private and group history, including fixes for migrated group records appearing in private search, group-message access from private chats, and previews being routed to the wrong conversation.

### Notes

Sketch conversion prioritizes appearance, so complex regions may be images. The editable-text artboard requires the corresponding fonts on the receiving computer. Web interactions and responsive rules are not converted into native Sketch behavior. This release passes the official file-structure validation and internal visual comparisons; import in the Sketch/Figma clients has not yet been verified.
