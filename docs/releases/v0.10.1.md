# AelionBot v0.10.1

本版统一主会话、Bot 私聊和群聊的消息样式，仅提供 Windows x64 安装包。

- 调整对话底色和消息气泡的颜色、圆角、间距及宽度，使用户消息与 Bot 回复更容易区分。
- 同步代码块、引用、链接、Bot 提及及附件卡片的配色。
- 改善窄会话区域中长消息和代码块的布局，保留代码块滚动与复制功能。
- 保留 0.10.0 的 QEMU 退出清理、国内安装源回退、安装进度及缓存复用修复。

## 下载

- Windows x64：`AelionBot-Setup-0.10.1-x64.exe`，也可在客户端检查更新。
- 附带 `latest.yml`、差分更新文件和 `SHA256SUMS.txt`。
