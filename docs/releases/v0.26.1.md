# AelionBot v0.26.1

补上 v0.26.0 没发出安装包的 Intel Mac 测试，以及打开预览后会话跳走、工作目录条被挤爆的问题。

## 预览

- 侧栏预览把对话压窄后，仍停留在最新消息，不会跳回开头。
- 窄栏输入区把工作目录单独一行，过长目录名省略，不再和自动审批、发送挤在一起。

## 发布

- 模型空闲超时从真正发出请求开始计算，不再把第一次加载 HTTP 客户端算进去。v0.26.0 因此在 Intel Mac 测试失败，没有公开 Release。

## 下载

- Windows x64：`AelionBot-Setup-0.26.1-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.26.1-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.26.1-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
