# AelionBot v0.40.0

这一版集中处理长对话里的卡顿：打字、Bot 工作时的界面刷新和头像动画都更流畅了。

## 简体中文

### 发消息后不再卡住

- 修复在很长的对话里发送消息后，整个应用卡住十几秒甚至更久的问题。以前开始回复前要在主线程上统计整段历史的 token，几千条消息时会把窗口冻住；现在这项工作放到后台线程，界面保持可操作。

### Bot 工作时更流畅

- 以前每次有变化，应用都会把全部聊天记录重新发给界面（长对话约 20 MB），界面再整个重画一遍。现在只发送变化的部分，没变的消息不会重画。
- Bot 工作时打字、滚动不再一顿一顿的：测试中长卡顿帧从 3 秒多降到几乎没有，掉帧减少约 85%。
- 流式输出的文字单独刷新，不再带动整个界面。

### 打字更跟手

- 输入框的内容只刷新输入框本身，长对话里每次按键的处理时间下降约三分之一。

### 长对话

- 打开长对话时先显示最近的 80 段内容，往上滚动时自动加载更早的部分，阅读位置保持不变。
- 搜索和引用跳转仍然可以定位到更早的消息。

### 头像动画

- 头像的思考、工作、等待动画改由显卡合成，不再让整个页面每帧重新排版。几个 Bot 同时工作时，动画从约 27 帧恢复到满帧。头像外观不变。

## English

### No more freeze after sending

- Sending a message in a very long conversation could freeze the whole app for ten seconds or more while it counted the history's tokens on the main thread. Counting now runs on a background thread and the window stays responsive.

### Smoother while a Bot works

- Every change used to send the entire chat history to the window (about 20 MB for a long conversation), which then redrew everything. Only what changed is sent now, and unchanged messages are not redrawn.
- Typing and scrolling no longer stutter while a Bot works: in testing, long frames went from over 3 seconds to almost none, and dropped frames fell by about 85%.
- Streaming text refreshes on its own instead of the whole window.

### More responsive typing

- Typing only refreshes the composer; each keystroke in a long conversation takes about a third less time.

### Long conversations

- A long conversation opens with its latest 80 entries and loads earlier ones as you scroll up, keeping your place.
- Search and quote jumps still reach earlier messages.

### Avatar motion

- Thinking, working and waiting animations are composited by the GPU instead of laying out the page on every frame. With several Bots working, they run at full frame rate again instead of about 27 fps. Avatars look the same.
