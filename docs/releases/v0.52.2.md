# AelionBot v0.52.2

## 简体中文

### 记忆界面更简洁

- 记忆页优先显示自动记忆开关、范围选择、搜索和记忆内容。待确认内容、Bot 记忆设置、模型配置和整理记录按需展开。
- 每条记忆的来源、时间、置顶和遗忘操作收进详情，修改入口仍可直接使用。保存失败时保留编辑内容，加载失败可以重试，快速切换范围不会被旧结果覆盖。
- 私聊回复下的记忆提示合并重复条目，展开后区分本次记住和本次用到的内容，并保留撤销入口。显示归档时，待确认的记忆不会重复混入已有记忆列表。

### OpenCode 会话支持

- 添加或编辑 Provider 时自动识别 `opencode.ai` 及其子域名，已有配置也能直接使用。
- 模型请求携带每个会话独立且稳定的 `x-opencode-session`，重试、切换模型和重启后继续同一会话时保持一致。

## English

### Simpler memory controls

- The Memory page puts automatic memory, scope selection, search and saved content first. Pending confirmations, Bot preferences, model settings and consolidation history expand when needed.
- Sources, dates, pinning and forgetting are grouped under each memory's details, with editing still directly accessible. Failed saves preserve your edits, failed loads can be retried, and late results no longer overwrite a newly selected scope.
- Memory disclosures beneath chat replies remove duplicate entries and separate newly remembered facts from those used in the reply, while keeping undo available. Showing archived memories no longer mixes pending candidates into the saved list.

### OpenCode sessions

- Providers are detected automatically from `opencode.ai` and its subdomains when added or edited. Existing configurations also work without changes.
- Model requests include a distinct, stable `x-opencode-session` for each conversation, preserved across retries, model changes and continuing the same conversation after restarting the app.
