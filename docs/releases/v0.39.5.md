# AelionBot v0.39.5

这一版修好了长对话里输入框打字卡顿，并清理重复的记忆。

## 简体中文

### 输入更流畅

- 修复在消息很多的对话里打字明显卡顿的问题：以前每按一个键都要把整段对话重新整理一遍，几千条消息时每次要 60–80 毫秒；现在打字时不再重算，任务运行时刷新对话也快了约 20 倍。
- 对话的显示内容和顺序不变。

### 记忆

- 修复新建的 Bot 在第一次重启后，记忆里出现两条一样的内容。
- 升级后首次启动会自动清理已经产生的重复记忆：同一个 Bot 里内容相同的只保留一条，优先保留带来源记录的那条。不需要手动处理。

## English

### Smoother typing

- Typing no longer lags in long conversations. Every keystroke used to rebuild the whole conversation, 60–80 ms with a few thousand messages; typing now skips that work, and refreshing a conversation while a task runs is about 20 times faster.
- What the conversation shows, and its order, are unchanged.

### Memory

- A newly created Bot no longer shows each memory twice after its first restart.
- The first start after updating removes duplicates that already exist: each Bot keeps one copy of the same memory, preferring the one with its sources. Nothing to do by hand.
