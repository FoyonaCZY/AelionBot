# AelionBot v0.24.1

默认工作区对模型生效，以及同一轮独立工具可以并行。

- 会话没有单独选择工作目录时，会使用设置里的默认工作区；模型可以用本机工具读取其中的文件。输入框会显示这个默认目录。
- 默认工作目录改完即保存。
- 同一轮里互不干扰的工具调用会并行执行。电脑点击、打字、写入和命令仍按顺序，避免互相抢。

## 下载

- Windows x64：`AelionBot-Setup-0.24.1-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.24.1-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.24.1-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
