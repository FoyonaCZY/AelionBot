# AelionBot v0.25.3

通用 Bot 能看见正在跑的终端和后台任务，但不把每一步工具过程铺进对话。设计师点开 PPTX 会用同名 HTML 预览。

## 通用 Bot

- 输入框上方显示仍在运行的终端和后台任务，可单独停止。
- 当前步骤会带上命令或文件名；读取、搜索等中间过程仍不进聊天。
- 一轮里的命令、补丁和写入收成可展开的「本轮操作」。
- 计划卡片收起时显示正在做的那一步。
- 工作目录里的 `AGENTS.md` / `CLAUDE.md` / `.cursorrules` 会读进上下文，并标明不能扩大权限。

## 设计师

- 点 PPTX 附件或成果会改用同名 HTML 预览，不启动工作电脑做转换。
