# AelionBot v0.29.4

## 简体中文

### 设计师与画布

- 修复打开导出等预览菜单时画布闪烁的问题：截图绘制完成后再切换原生网页，关闭菜单时先恢复网页。
- 修复高 DPI 屏幕下菜单截图尺寸不匹配的问题，并处理快速开关菜单时的过期响应。
- 从其他 Bot 切换到设计师，或在设计师内切换任务时，会话自动定位到最新消息。
- 在底部时跟随新回复和内容高度变化；手动上翻后保留阅读位置，回到底部或发送消息后恢复跟随。

### 群聊与权限

- 修复群聊内部静默标记被当作消息发出的问题，包括带格式包裹的标记；在最终回复和消息发布入口统一拦截。
- 本地和远程 MCP 调用统一遵循所选权限模式：“每次询问”由用户确认，“自动审批”交给审批模型，“完全访问”直接执行。工作电脑接管仍单独处理。
- 同步更新权限模式说明、使用文档，以及官网产品介绍文章与配图。

## English

### Designer and canvas

- Fixed canvas flicker when opening export and other preview menus. The replacement screenshot is painted before the native page is hidden, and the page is restored before the screenshot is removed.
- Fixed screenshot sizing on high-DPI displays and stale responses when menus are opened and closed quickly.
- Switching from another Bot to a Designer, or switching design tasks, now opens the conversation at its latest message.
- New replies and content-size changes are followed while at the bottom. Scrolling up preserves the reading position; returning to the bottom or sending a message resumes following.

### Group chats and permissions

- Fixed internal group silence markers appearing as public messages, including formatted markers. They are intercepted before final replies and messages are published.
- Local and remote MCP calls now consistently follow the selected permission mode: Ask requests user confirmation, Auto Approval uses the approval model, and Full Access executes directly. Work-computer takeover remains separate.
- Updated permission-mode descriptions, usage documentation, and the website product article and screenshots.
