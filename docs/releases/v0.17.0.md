# AelionBot v0.17.0

本版简化技能和模型设置，调整默认本机权限模式，仅提供 Windows x64 安装包。

- 技能页移除底部“扫描位置与来源”区域。
- 共享技能自动发现只扫描用户及项目的 `.agents/skills`，不再自动加载其他 Agent 的私有技能目录；Aelion 自身技能和手动添加的目录继续使用。
- 默认本机权限改为自动审批：普通项目读写直接放行，需要审核的操作交给默认模型；无法确定时再请求用户确认。已有手动选择的权限模式保留。
- 移除模型设置中的“图片输入”选项，继续使用模型能力识别和图像兼容处理。

## 下载

- Windows x64：`AelionBot-Setup-0.17.0-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
