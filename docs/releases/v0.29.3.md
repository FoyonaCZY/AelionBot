# AelionBot v0.29.3

## 简体中文

### 导出修复

- 修复包含大图片的设计无法导出 Sketch 的问题。导出页面改用内存中的短地址加载，避免内嵌资源使地址过长；PDF、PNG 和 SVG 也使用同一修复。
- 整页导出会主动加载页面下方的懒加载图片，避免一直等待或超时。
- 屏幕外的辅助文字（例如“跳到主要内容”链接）不再因缺少截图区域而阻断 Sketch 导出。

### 导出状态

- 开始导出后，按钮显示“导出中”并禁止重复提交。
- 工具栏下方显示独立状态栏，不会被原生网页画布遮住。
- 成功显示保存位置，失败显示具体原因并提供“重试”；取消保存也有明确提示。

已使用实际的大图片设计验证 Sketch 文件生成，并增加真实 Electron 渲染回归测试。

## English

### Export fixes

- Fixed Sketch export failing for designs with large images. Export pages now load through a short in-memory URL, avoiding navigation limits caused by embedded resources. PDF, PNG, and SVG exports use the same fix.
- Full-page export now triggers lazy-loaded images below the viewport instead of waiting indefinitely or timing out.
- Off-canvas accessibility text, such as skip-to-content links, no longer blocks Sketch export when no screenshot region is available.

### Export status

- The export button shows “Exporting” and prevents duplicate submissions until the operation finishes.
- A separate status bar appears below the toolbar, outside the native web canvas so it remains visible.
- Successful exports show the saved location. Failures show a specific error and a Retry action. Cancelling the save dialog also shows an explicit status.

Verified Sketch file generation with a real design containing large images, and added a native Electron rendering regression test.
