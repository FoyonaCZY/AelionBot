# AelionBot v0.7.5

本版增加诊断日志与问题反馈入口，并支持自定义 Bot 头像配色，仅提供 Windows x64 安装包。

## 诊断与反馈

- 「设置 → 关于 → 问题反馈」支持预览、刷新和导出诊断 ZIP，包含应用与系统环境、近期错误、任务执行状态和工作电脑日志。
- 导出时对密钥、授权信息和个人目录进行脱敏，排除聊天正文、附件、截图、工具参数及输出、配置文件和虚拟机磁盘。
- GitHub 反馈页面会预填诊断摘要和报告编号，用户可补充复现步骤、截图并附上导出的日志包后提交。
- 新增应用启动、接口失败和页面错误记录；日志采用大小限制与轮换，导出支持日志缺失或截断的情况。

## Bot 头像配色

- 新建 Bot 和编辑资料时均可选择纯色、渐变或拼色头像，支持预设、自定义颜色、随机配色及恢复原版紫色。
- 渐变可调整方向，拼色提供弧线、斜切、左右、波纹、上下和色块等方式。
- 配色随 Bot 保存，侧栏、会话和成员提及同步显示，重启后保留设置。
- 保留无关界面刷新时的头像节点，避免切换页面或输入消息反复重置头像动画。

## 下载

- Windows x64：`AelionBot-Setup-0.7.5-x64.exe`，也可在客户端检查更新。
- 附带 `latest.yml`、差分更新文件和 `SHA256SUMS.txt`。
