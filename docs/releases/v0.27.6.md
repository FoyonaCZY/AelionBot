# AelionBot v0.27.6

生图协议猜错时会回退，并记住这个模型真正走通的通道。

## 生图

- 先按模型名猜测 Gemini `generateContent`、Responses 托管生图或 `/images/generations`。失败则试其余通道（Responses 只在 Provider 本身是 Responses 时才试）。
- 成功后按 Provider、Base URL 和模型名记下来，下次同一模型直接走记住的那条。
