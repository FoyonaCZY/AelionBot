# AelionBot v0.27.9

生图协议改成设置里选定，不再每次猜测后轮流试接口。设计师写作时能看到手艺要求和实时检查。预装技能不再把模型推向更差的搜索或桌面操作。

## 生图

- 在 Provider 设置里选定协议：OpenAI Images、Gemini、Responses 托管生图或 SD WebUI。选定后不再逐次探测，失败也不会换接口重试并重复计费。
- 可以指定画幅、质量和参考图。工具失败时给出下一步，而不是只报内部协议名。
- 设置里可以测试生图连接。

## 设计师

- 设计任务按工作流注入与品牌无关的手艺说明，并使用设计系统里的组件参考。
- 写入文件时更新检查结果。严重问题仍会挡住交付，其余显示为提示。

## 预装技能

- 网页调研在服务端搜索打开时使用它，不再去找已被隐藏的客户端 `web_search`。普通静态页用 `web_read` 核对；只有需要脚本或登录时才打开工作电脑浏览器。
- 办公应用和桌面浏览器只在任务需要时打开，不能代替搜索、读网页或本机项目修改。
