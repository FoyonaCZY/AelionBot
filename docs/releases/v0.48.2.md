# AelionBot v0.48.2

## 简体中文

### 界面

- 改进深色模式：主屏侧栏、对话卡片、消息气泡、插件页和设置弹窗使用分层更明确的深色表面与边框，提升文字和控件对比度。
- 修复 Windows/Linux 窗口右上角控制区与页面背景的色差：原生 caption overlay 和顶部环境条现在使用同一底色，并随深色模式同步。

## English

### Interface

- Improved dark mode with clearer surface separation and borders across the sidebar, conversation card, message bubbles, plugins page and settings dialog, improving text and control contrast.
- Fixed the colour mismatch around the Windows/Linux caption controls: the native caption overlay and the top ambient strip now share the same background and follow dark mode.
