# AelionBot v0.23.4

群聊路由、提问说明显示，以及 CSV 预览。

- 群聊会按被点名的伙伴分发，不再一律交给协调 Bot。
- 模型在提问时写的说明会先出现在会话里，再等待你回答。
- CSV 预览可以滚动查看全部行列，不再悄悄丢掉后面的行。

## 下载

- Windows x64：`AelionBot-Setup-0.23.4-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.23.4-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.23.4-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
