# AelionBot v0.52.1

## 简体中文

### 企业微信群里分得清是谁在说话

- 群里不同的人 @ Bot 时，Bot 不再都当成管理员。系统提示里的用户资料会换成最新发言人的信息，平台给了什么就填什么：企业微信只提供账号 ID，所以 Bot 会用 ID 称呼对方。
- 连接器的主人、在电脑上发的消息和定时任务，仍然使用你填写的个人资料。
- 每条来自聊天软件的消息都带上发送人，Bot 能分清群聊记录里谁说了什么。飞书和微信里主人以外的人私聊时也一样。

### 飞书能收到你发的图片和文件了

- 修复在飞书里给 Bot 发图片、文件、语音、视频时报错 `Request failed with status code 400`、附件收不到的问题。
- 连续发几张图或一张图加一句说明，仍然合并成一条消息交给 Bot，每个附件都能收下。群里不同的人同时发言不再被合并。

## English

### WeCom groups: the Bot knows who is speaking

- When different people @-mention the Bot in a group, it no longer takes them all for the administrator. The user profile in the system prompt now holds what the platform reports about the latest speaker. WeCom provides only an account ID, so the Bot addresses people by it.
- The connector's owner, messages written on the computer and scheduled tasks still use the profile you filled in.
- Every message from a chat app now names its sender, so the Bot can tell who said what in a group's history. The same goes for private chats with people other than the owner on Feishu and WeChat.

### Feishu delivers the pictures and files you send

- Fixes pictures, files, audio and video sent to a Bot on Feishu failing with `Request failed with status code 400` and never arriving.
- A few pictures in a row, or a picture and a caption, still reach the Bot as one message, and every attachment arrives. Different people speaking at once in a group are no longer merged.
