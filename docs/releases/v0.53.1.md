# AelionBot v0.53.1

## 简体中文

### 用量页重新设计

- 总览合成一张卡片：总 tokens 放在最上面，下面一条细条显示缓存输入、新增输入和输出各占多少，再下面是请求数（含失败次数和失败率）、缓存命中率和平均每次请求。
- 用量趋势改成柱状图，刻度取整数，日期显示成“11月8日”。鼠标停在柱子上可以看当天的数值和请求数；没有返回用量的日子不会画成 0。
- “按 Provider”和“按模型”两张排行并排显示，点一行就按它筛选。
- 切换时间范围或筛选时，先保留上一份结果，新数据到了再替换，页面不会闪。

### 更新

- 发现新版本后，应用仍会定时检查有没有更新的版本。等待更新期间如果又发了新版，会直接换成最新的那个；已经下载好的安装包也会换成最新版，只需要更新一次。
- 更新后第一次打开，会弹窗列出从你上次看过的版本以来所有版本的更新说明。从 v0.53.0 或更早的版本更新时，只显示这个版本的说明。

## English

### Redesigned Usage page

- The overview is now one card: total tokens on top, a thin bar showing how much is cached input, new input and output, then requests (with failures and failure rate), cache hit rate and average per request.
- The usage trend is a column chart with round axis values and dates like "Nov 8". Hover a column for that day's amount and request count; days whose requests returned no usage are not drawn as zero.
- "By Provider" and "By model" sit side by side; click a row to filter by it.
- Changing the range or a filter keeps the last result on screen until the new one arrives, so the page no longer flashes.

### Updates

- After finding an update, the app keeps checking for newer ones. If another version comes out while you wait, the newest replaces it, and a downloaded installer is replaced too, so you only update once.
- The first launch after updating shows the notes of every version since the one you last saw. When updating from v0.53.0 or earlier, only this version's notes are shown.
