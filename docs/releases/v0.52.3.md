# AelionBot v0.52.3

## 简体中文

### 连接多个企业微信机器人

- 可以连接多个企业微信机器人，每个机器人交给一个 Bot 回复。想让几个 Bot 都能在企业微信里用，就为每个 Bot 各建一个机器人，分别添加。
- “插件 → 消息渠道”的标题旁多了“添加”，已经连上一个之后也能再加。默认打开最近添加的平台，并选好一个还没连接这个平台的 Bot。
- 同一个平台连接了好几个时，列表和详情里的名称会带上 Bot 名，例如“企业微信 · 设计师”，一眼分得清。
- 每个机器人各自配对：第一次给新机器人发消息时，仍要在电脑上确认一次配对码。

## English

### Connect several WeCom bots

- You can now connect several WeCom bots, each answered by one Bot. To have more than one Bot reply in WeCom, create a WeCom bot for each and add them one by one.
- “Plugins → Messaging” now has an Add button next to its title, so you can add another connector after the first. It opens the platform you added last and picks a Bot that isn't connected to that platform yet.
- When a platform has several connectors, the list and the details show the Bot's name too, such as “WeCom · Designer”, so they're easy to tell apart.
- Each bot pairs on its own: the first time you message a new WeCom bot, you still confirm a pairing code on the computer.
