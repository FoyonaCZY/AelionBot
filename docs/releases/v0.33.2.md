# AelionBot v0.33.2

## 简体中文

v0.33.1 的安装包未能完成发布，本版本包含其全部内容。

### 性能

- 长对话中收到新状态或流式输出时，不再重新渲染未变化的消息和 Markdown，任务运行中的界面更流畅。

### Claude 服务端网页搜索

- 使用 Claude Messages 协议的 Provider 可以在设置里打开「服务端搜索」，由 Claude 直接联网搜索（`web_search_20250305`，每次请求最多 5 次），开启后不再提供应用内的 web_search。默认关闭；第三方中转如不支持会返回 400，关闭即可恢复。
- 长时间搜索时 Claude 会暂停回合，应用会自动续跑并合并为一条回复；搜索结果和引用会原样保留，供后续对话使用。

### 工具结果卡片

- 搜索和查找文件的结果按文件分组，显示行号和上下文，不连续的行之间有分隔。
- 目录列表显示为图标网格，修改文件只显示一行文件名、路径和大小。
- 其他工具结果去掉了分页、校验和等内部字段，改为左对齐。

### 提示词优化

- 每条规则只说明一次；只提到当前真正可用的工具，无人值守运行不再收到无法执行的指令。
- 个人资料和长期记忆不再重复注入，已经重复保存的记忆在读取时也只出现一次；替换记忆时如果新内容已存在，会合并为一条。
- 设计师和群聊的提示词按主题整理，工具说明里重复的授权说明已去掉。

## English

v0.33.1 installers were never published; this release includes all of its changes.

### Performance

- In long conversations, new state and streaming updates no longer re-render unchanged messages and Markdown, so the interface stays smoother while a task runs.

### Claude hosted web search

- Providers using the Claude Messages protocol can turn on "Server-side search" in settings, letting Claude search the web itself (`web_search_20250305`, up to 5 searches per request); the in-app web_search tool is hidden while it is on. It is off by default; if a third-party relay rejects it with a 400, turn it off.
- When a long search pauses Claude's turn, the app resumes it automatically and merges it into one reply; search results and citations are kept for the rest of the conversation.

### Tool result cards

- File search and find results are grouped by file with line numbers and context, and gaps between lines are marked.
- Directory listings show as an icon grid, and file edits show one line with the file name, path and size.
- Other tool results drop internal paging and checksum fields and read left-aligned.

### Prompt improvements

- Each rule is stated once, and only tools that are actually available are mentioned, so unattended runs no longer receive instructions they cannot follow.
- Your profile and long-term memories are no longer injected twice; memories already saved twice appear once, and replacing a memory with text that already exists merges the two.
- Designer and group prompts are reorganized by topic, and repeated authority notes were removed from tool descriptions.
