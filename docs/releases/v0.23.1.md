# AelionBot v0.23.1

预览反馈在会话里只显示你写的意见。

- 从预览发送修改意见时，聊天里显示你输入的文字；发给模型的完整说明（文件、页码、截图范围）仍会保留。
- 回复引用也使用这条意见，而不是整段预览模板。

## 下载

- Windows x64：`AelionBot-Setup-0.23.1-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.23.1-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.23.1-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
