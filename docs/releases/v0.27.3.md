# AelionBot v0.27.3

修掉 v0.27.2 在 pnpm 下打 Mac 包找不到 `resedit`，以及 Windows 后台进程测试偶发读不到输出。

## 发布

- `resedit` 改为直接依赖。Mac 打包不再在启动时加载 Windows 图标工具。
- 本机后台进程测试拉长等待，并用 `Write-Output` 写出就绪标记。

## 下载

- Windows x64：`AelionBot-Setup-0.27.3-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.27.3-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.27.3-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
