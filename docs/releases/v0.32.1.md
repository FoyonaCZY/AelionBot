# AelionBot v0.32.1

## 简体中文

### 思考过程

- 模型返回可读的推理内容时，回复上方显示一行思考过程。思考期间显示已用秒数和最新几行推理；开始输出正文或调用工具后收起为「已思考 N 秒」，点击可展开。
- 支持 Claude 的 thinking、Responses 的推理摘要（现在会请求 `summary: 'auto'`）、Chat 协议的 `reasoning_content` / `reasoning` / `reasoning_details` 和带标签的内容，以及 Gemini 的思考内容（设置了思考预算时开启 `includeThoughts`）。
- 推理内容只保存在聊天消息上用于显示，最多 20,000 字符，不会进入发给模型的历史。群聊和 Bot 之间的私聊不显示。
- 「设置 → 外观」新增展示方式：自动收起、始终展开或不显示。

## English

### Thinking

- When a model returns readable reasoning, a thinking line appears above the reply. While it thinks, the line shows the elapsed seconds and the newest reasoning lines; once text or a tool call starts, it collapses to "Thought for Ns" and can be expanded.
- Reasoning is read from Claude thinking blocks, Responses reasoning summaries (now requested with `summary: 'auto'`), chat `reasoning_content` / `reasoning` / `reasoning_details` and tagged content, and Gemini thoughts (`includeThoughts` when a thinking budget is set).
- Reasoning is stored on the chat message for display only, up to 20,000 characters, and never enters the history sent to the model. Group chats and Bot-to-Bot threads do not show it.
- Settings → Appearance adds a display option: collapse automatically, always expanded, or hidden.
