# AelionBot v0.27.0

设计师任务打开后就能对着实时画布看稿。Responses 的服务端搜索和生图回到 Provider，图片输入按模型列表识别，不再让用户逐项勾选。

## 设计师

- 任务内左右分栏：左边会话，右边画布。HTML 一写入就会出现，不必等到最后交付。
- 可导入本地 DESIGN.md 品牌包，画布批注会钉到 `data-design-id`。演示可导出 PDF，并支持手机稿和多页文档。
- 画布分栏留在设计师工作区里，不再把整个窗口收成文件预览的窄栏，也不会改普通网页预览的比例。侧栏和「当前成果」仍在。
- 没选设计系统时，`design_resource` 不再把整轮判失败。已绑定的任务可以用 `design_system` 补选；误调 `design_start` 并带上系统 ID 时，会挂到当前任务上。

## 模型与设置

- Responses 的服务端网页搜索和图片生成在 Provider 上开关，不再出现在每个模型卡片里。目录里旧的勾选会折到对应 Provider。
- 是否支持图片输入由拉取模型列表时的接口元数据决定，设置里不再提供勾选。已有 Bot 的模型选择、密钥和对话不会被覆盖。
