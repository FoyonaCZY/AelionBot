# AelionBot v0.36.0

## 简体中文

### 设计师工作室

- 顶栏可以在「对话 / 分栏 / 画布」三种布局间切换。分栏时拖动中间的分隔线调整对话宽度（360–640px），会记住上次的宽度；画布布局下对话收成左侧细栏，输入框浮在画布下方，上面显示最新回复的摘要。
- 移动端原型现在显示在手机外框里并居中，不再铺满画布。可以选 Pixel 8、iPhone 16、深色，或者两台并排对比（浅色和深色，或两种机型）。
- 每轮产出合成一张「第 N 轮产出」卡片：同一个文件只列一次，并显示这一轮改了几次、增删了多少行。
- 交付状态分成「生成中 / 有阻塞问题 / 待确认 / 已确认」；有阻塞问题时不能确认交付。
- 去掉了「可选检查」。

### 文件预览

- 对话里打开的文件预览和设计师画布使用同一套面板：一行工具栏，预览、源码、编辑、标注合成一组切换，颜色跟随应用的浅色或深色。
- 标注工具只在「标注」模式下出现。圈选和元素批注显示在对话输入框里，可以单独删除，发送时连同截图一起带上；预览底部不再有第二个输入框。
- 在设计师画布里发送修改意见也会带上截图和标注。

### 计划和目标卡片

- 收起时只占一行：状态圆点、目标、当前步骤和进度，下面一条细进度线；暂停移到「⋯」菜单里。
- 修复了卡片收起时点「⋯」菜单被截掉的问题。

### 其他修复

- 群聊狼人杀：Claude 等模型在 JSON 前后附带说明文字时也能正常解析行动；仍然无法解析时，运行记录里会保留模型的原始回复，方便排查。

## English

### Designer studio

- Switch between Chat, Split and Canvas layouts from the header. In Split, drag the divider to set the conversation width (360–640 px); it is remembered. In Canvas, the conversation folds into a thin rail and the composer floats under the canvas with a one-line summary of the latest reply.
- Mobile prototypes now sit centred in a phone frame instead of filling the canvas. Choose Pixel 8, iPhone 16, dark mode, or two devices side by side (light and dark, or two models).
- Each round's output is one "Round N output" card: every file is listed once, with how many times it changed and how many lines were added and removed.
- Delivery shows one of four states: Working, Blocking issues, Ready to confirm and Confirmed. Blocking issues prevent confirming.
- Optional checks have been removed.

### File preview

- File previews in chats and the designer canvas share one panel: a single toolbar, one switch for Preview, Source, Edit and Annotate, and colours that follow the app's light or dark theme.
- Annotation tools appear only in Annotate mode. Region and element marks show up in the conversation composer, can be removed one by one, and are sent with a screenshot; the second input box under the preview is gone.
- Feedback sent from the designer canvas now includes the screenshot and marks as well.

### Plan and goal cards

- Folded cards take one line: status dot, objective, current step and progress, with a hairline progress bar underneath. Pause moved into the "⋯" menu.
- Fixed the "⋯" menu being cut off when the card is folded.

### Other fixes

- Werewolf in group chats: actions from models such as Claude now parse when the JSON is wrapped in explanatory text. When a reply still cannot be parsed, the run records keep the model's raw reply for diagnosis.
