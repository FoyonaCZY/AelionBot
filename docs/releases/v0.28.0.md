# AelionBot v0.28.0

群聊新增「AI 游戏」入口，可以和 Bot 玩十二人狼人杀，也可以旁观全 AI 对局。

## AI 游戏

- 提供预女猎白、预女猎守两个十二人板子，包含警长竞选、警徽流转、夜间行动、发言、投票和胜负结算。
- 支持逐个或批量配置 AI 模型与 MBTI 性格，临时 Bot 可以补齐座位。
- 狼队夜间分提议、回应、确认三轮讨论；真人狼人可以连续发言，点击结束讨论后推进。
- 提供角色攻略、玩家决策记录及模型请求状态。模型返回的决策说明属于自述，不代表人格影响的因果证明。
- 对局支持暂停、恢复和结束，重启后可恢复。模型失败时暂停并保留已完成选择，排队时间不占响应预算。
- 游戏上下文按玩家隔离，夜间时钟不会向普通玩家暴露狼人的座位。
