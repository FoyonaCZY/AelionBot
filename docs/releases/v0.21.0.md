# AelionBot v0.21.0

本版预装办公与研究技能，并在输入栏显示上下文占用。

## 预装技能

安装包内置八个只读技能，新用户和已有用户都可以直接使用，不会覆盖你自己添加的技能：

- PDF 处理、文档写作、表格、演示文稿
- 网页调研、数据分析、代码开发、界面设计

技能随应用更新；许可证与上游来源记录在各技能目录和 `assets/skills/manifest.json`。

## 上下文占用

主会话输入栏显示最近一次请求的估算占用，可展开查看系统提示词、对话、技能、工具、MCP、工具结果和图片的占比。

## 下载

- Windows x64：`AelionBot-Setup-0.21.0-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.21.0-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.21.0-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
