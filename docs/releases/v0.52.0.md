# AelionBot v0.52.0

## 简体中文

### 长期记忆重做

- **不用说“记住”也会记。** 一段对话安静 90 秒后，应用读一遍这段对话，记下以后用得上的事和做过的事。说了“记住”“更正”“忘记”的，当场生效。
- **不再有容量上限。** 记忆拆成一条条独立的事实，带类型和有效期。每次对话只带最重要的一小部分，其余的在相关时才想起。
- **四个范围。** 关于你（所有 Bot 共用）、每个 Bot 自己的、每个项目的（按 git 仓库，多个克隆共用）、每个群的。已有的记忆留在原来的 Bot 里，像是关于你的条目会出现在“等你确认”，你同意后才让所有 Bot 知道。
- **看得见、改得了。** 设置的记忆页可以修改、忘记、置顶，查看为什么记得；还能看做过的事、整理记录，导入和导出。回复下方显示“想起了 3 条 · 记住了 1 条”，不对的当场撤销。
- **来源决定可信度。** 只有你说过的话和本地工具的实际结果才能成为事实。网页、MCP、附件和其他 Bot 的内容不会变成事实；读过这些内容后 Bot 自己想记的，要你确认。其他人在连接器里说的话只留在那个 Bot，并标明是谁说的。
- **空闲时整理。** 合并重复的、拆开混在一起的、归档过时的，每次都可以整次撤销。
- **搜索更好用。** Bot 回查历史时可以直接用自然语言提问，不带空格的中文问句也能搜到。可选的语义检索在本机运行一个约 25 MB 的小模型，内容不会发出去；模型文件在启动后自动下载，可以在设置里关掉。
- **忘记是真的忘记。** 文字会从数据库和修改历史里清除，也不会被自动记回来。原始对话还在，已经发给模型服务的内容无法追回。
- 不想被记住时，可以在消息里说“这次不要记”，或在 + 菜单里让这段对话不记入记忆，也可以让某个 Bot 只用不记。

后台提取和整理默认用每个 Bot 自己的模型，会花模型额度，用量在“用量”里单独显示。可以在记忆设置里换成便宜的模型，或关掉“自动记忆”。

### 后台学习修好了

- 后台复盘之前大多因预算耗尽而失败，什么也写不下来。现在它只带用得上的工具和一份较短的摘要，定时任务也不再触发复盘。
- 数据文件会回收已删除内容占用的空间。升级后第一次启动会多花几秒。

### 悬浮终端

- 聊天右上角新增终端按钮，打开一个运行在这台电脑上的悬浮终端，起始目录是当前会话的工作目录。可以拖动、调整大小；隐藏后 shell 继续运行。
- 这里输入的命令不经过本机权限模式，Bot 也读不到这个终端。

## English

### Long-term memory, rebuilt

- **No need to say "remember".** Once a conversation has been quiet for 90 seconds, the app reads it and keeps what will be useful later, along with what was done. "Remember", "correct" and "forget" still take effect at once.
- **No more size limit.** Memories are now separate facts with a type and a validity period. Each conversation carries only the most important few; the rest come up when they are relevant.
- **Four scopes.** About you (shared by all Bots), each Bot's own, each project's (by git repository, shared by clones) and each group's. Existing memories stay with their Bot. Those that look like they are about you appear under "Waiting for you", and reach other Bots only if you agree.
- **Visible and editable.** The Memory settings page lets you edit, forget and pin memories and see why one is kept, along with what was done, the consolidation log, import and export. Below a reply, "Recalled 3 · Remembered 1" lets you undo a wrong one on the spot.
- **Trust comes from the source.** Only what you said and what local tools actually returned can become facts. Webpages, MCP, attachments and other Bots cannot. What a Bot wants to keep after reading such content waits for your confirmation. What other people say in a connector chat stays with that Bot, under their name.
- **Tidied up when idle.** Duplicates are merged, mixed entries split and outdated ones archived. Each pass can be undone as a whole.
- **Better search.** Bots can look through history with natural questions, including Chinese without spaces. Optional semantic search runs a small model of about 25 MB on this computer and sends nothing out. Its files download automatically after launch, and it can be turned off in settings.
- **Forgetting means forgetting.** The text is removed from the database and the change history, and is not learned again. The original conversation remains, and what was already sent to a model service cannot be recalled.
- To keep something out of memory, say "don't remember this" in your message, use the + menu for the whole conversation, or set a Bot to use memories without adding new ones.

Background capture and consolidation use each Bot's own model by default, which spends your model quota; the usage is listed separately under Usage. You can pick a cheaper model in Memory settings or turn off automatic memory.

### Background learning works again

- Background reviews mostly ran out of budget before writing anything. They now carry only the tools they can use and a shorter digest, and scheduled tasks no longer trigger them.
- The data file now gives back space from deleted content. The first launch after updating takes a few seconds longer.

### Floating terminal

- A new terminal button at the top right of the chat opens a floating terminal on this computer, starting in the conversation's working folder. Drag and resize it; the shell keeps running while it is hidden.
- Commands typed here do not go through the local permission mode, and Bots cannot read this terminal.
