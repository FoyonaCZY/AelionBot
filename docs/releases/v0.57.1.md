# AelionBot v0.57.1

## 简体中文

### 设计预览与知识库

- 设计系统库用同一张柑橘静物照片展示各套风格的配色、字体和构图，便于比较最终效果。
- 群聊和消息中的设计任务卡会显示作品首屏。点击卡片即可打开任务；还没有可预览页面时，卡片显示文件类型图标。
- 知识库首次打开时会显示档案静物配图，可以从图上的「新建」开始添加资料。建库后该位置显示知识库列表。

### 工作区媒体模型与 Higgsfield

- Bot 共用工作区的图片、视频和语音设置，生图和生视频时仍可按次指定 Provider 和模型。画幅、分辨率和时长支持自定义。
- 视频协议新增 **Higgsfield**，共提供 15 种协议适配。使用官方 API 时，选择 Higgsfield，服务地址填 `https://api.higgsfield.ai`，API Key 填控制台复制的完整凭据，模型 ID 填具体端点路径，例如 `bytedance/seedance-2.0/text-to-video`。
- 支持用本地图片或视频作为 Higgsfield 的生成素材。客户端通过签名地址上传文件，并按任务 ID 查询结果；恢复查询时复用已提交的任务。

## English

### Design previews and the knowledge library

- Design system samples use the same citrus photograph to show how each system handles color, type, and composition.
- Design task cards in group chats and messages show the first screen of the work. Click a card to open the task. Tasks without a previewable page keep their file-type icon.
- An archive photograph frames the New action in an empty knowledge library. After the first library is created, the list takes its place.

### Workspace media models and Higgsfield

- Bots share workspace image, video, and speech settings. Individual image and video requests can select a different provider and model, with custom aspect ratios, resolutions, and durations.
- **Higgsfield** brings the number of video protocol adapters to 15. For the official API, select Higgsfield, enter `https://api.higgsfield.ai` as the base URL, and paste the full credential from the API console. Use the endpoint path as the model ID, for example `bytedance/seedance-2.0/text-to-video`.
- Local reference images and videos are uploaded using signed URLs. AelionBot retrieves the result by task ID and can resume polling an existing generation.
