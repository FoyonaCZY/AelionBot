# AelionBot v0.7.3

本版调整单次任务的累计模型用量限制，仅提供 Windows x64 安装包。

## 改进

- 单次任务的累计 Token 用量默认不限，不再因为达到默认的 50 万 Token 上限而暂停。
- 在「设置 → 运行 → 每次模型用量上限」中可以自行设置上限，`0` 表示不限，填写正数后启用限制。
- 升级后首次启动时，旧版保存的 50 万 Token 预设会改为不限，其他自定义上限保留。之后手动设置的上限会正常保存，重启后仍生效。
- 模型用量继续记录；启用上限时仍累计本次任务的输入与输出 Token，服务未返回用量时采用估算值。

## 下载

- Windows x64：`AelionBot-Setup-0.7.3-x64.exe`，也可在客户端检查更新。
- 附带 `latest.yml`、差分更新文件和 `SHA256SUMS.txt`。
