# AelionBot v0.14.0

本版优化提示词缓存复用并调整用量展示，仅提供 Windows x64 安装包。

- 将固定规则、项目参考资料与本轮动态状态分层，减少时间和任务 ID 对历史缓存复用的影响。
- Responses 使用稳定会话缓存键，兼容接口明确不支持时自动降级；Anthropic 增加缓存断点并保留原始推理内容。
- 增加请求前缀指纹诊断，记录变化位置，不记录提示词原文。
- 缓存命中率改为“缓存读取 Token ÷ 总输入 Token”；未返回缓存明细按未命中处理，卡片、模型明细和趋势图采用一致口径。
- 移除用量卡片底部说明文字。

## 下载

- Windows x64：`AelionBot-Setup-0.14.0-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
