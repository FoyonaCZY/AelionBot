# AelionBot v0.24.0

预览工作台：标注、检查元素，以及把网页改动发给伙伴。

- 文件和网页预览可以画框、箭头、笔迹和文字，截图反馈会带上这些标注。
- 网页可以检查元素、改样式和 HTML。工作区里的静态 HTML 会写回源文件；正在运行的页面会把改动清单发给对应会话，由伙伴去改项目源码。
- 并排预览和会话共用输入框；全屏预览仍用浮动输入。未保存的改动会在切换、导航或关闭前提示。

## 下载

- Windows x64：`AelionBot-Setup-0.24.0-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.24.0-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.24.0-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
