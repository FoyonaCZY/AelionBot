# AelionBot v0.21.2

上下文占用、文件预览和自动审核模型的小版本。

- 上下文占用用模型返回的实际输入用量校准总量；分类仍是估算。有服务端数字时会标明。
- 新增 `open_preview`：伙伴可以把工作电脑、本机或已有附件打开到现有预览器，不代替发送原文件。
- 设置里可单独指定自动审核模型，和聊天默认模型分开。
- 模型连接超时、限流和重试时的工作状态说明更清楚。

## 下载

- Windows x64：`AelionBot-Setup-0.21.2-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.21.2-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.21.2-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
