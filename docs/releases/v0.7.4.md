# AelionBot v0.7.4

本版增加自动检查更新和侧栏更新入口，仅提供 Windows x64 安装包。

## 改进

- 客户端启动 30 秒后自动检查更新，尚未发现新版本时每 5 分钟继续检查，网络失败后也会重试。
- 发现新版本后，左下角「设置」旁会显示小「更新」按钮，点击即可进入「关于」中的更新页面。
- 下载期间，侧栏按钮显示下载百分比；下载完成后显示「重启更新」。取消或下载失败后仍可从这里继续操作。
- 后台检查保留输入草稿与焦点。下载和重启安装由用户点击执行，定期检查不会覆盖已发现的版本或正在进行的下载。

## 下载

- Windows x64：`AelionBot-Setup-0.7.4-x64.exe`，也可在客户端「设置 → 关于」检查更新。
- 附带 `latest.yml`、差分更新文件和 `SHA256SUMS.txt`。
