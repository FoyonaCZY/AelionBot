# AelionBot v0.57.2

## 简体中文

### Provider 地址与模型目录

- 保存连接时保留填写的 Base URL 路径。自定义兼容网关可以直接使用根地址，也可以填写自己的版本号和租户前缀。
- 只启用媒体用途的连接也可以按协议刷新模型。Higgsfield 使用官方公开目录并按图片和视频区分端点；fal 使用公开视频分类。百炼、方舟、xAI、MiniMax、Replicate、Vertex AI 和 Stable Diffusion WebUI 使用对应的服务目录。支持手动填写模型 ID。
- 升级时会修正旧版给 Higgsfield 官方根地址自动写入的 `/v1`，保留连接 ID、凭据和已有模型分配。

### Higgsfield 原生生图

- 在「设置 → 模型」中可选择 Higgsfield 生图协议。Bot 可以调用原生端点生成图片，也可以把本地参考图上传至签名存储地址后进行编辑。
- 设置页测试生图和设计任务使用相同的协议实现。应用查询已提交的任务，取回实际的图片文件。

## English

### Provider URLs and model discovery

- Saving a connection preserves the supplied base URL path. Custom compatible gateways can use an unversioned root, an explicit API version, or a tenant prefix.
- Media-only connections can refresh the catalog supported by their protocol. Higgsfield uses its public catalog and separates image and video endpoints. fal queries public video categories. DashScope, ModelArk, xAI, MiniMax, Replicate, Vertex AI, and Stable Diffusion WebUI use their respective catalogs. Custom model IDs can still be entered manually.
- Upgrading repairs the `/v1` suffix previously written to the official Higgsfield base URL while retaining the connection ID, credentials, and existing model assignments.

### Native Higgsfield image generation

- Select the Higgsfield image protocol in Settings → Models to generate images through native endpoints. Image editing can upload local reference images using signed storage URLs.
- The settings connection test and design tasks use the same implementation. AelionBot polls the submitted job and retrieves the resulting image file.
