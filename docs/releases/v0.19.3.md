# AelionBot v0.19.3

本版移除程序附加的回复语言限制，改善群聊提示词与界面，并修复工作电脑初始化问题，仅提供 Windows x64 安装包。

- 主会话、群聊、开场白及自动审批不再强制指定输出语言，也不再按界面语言或最新真人消息额外设置语言策略；模型自行根据对话决定。
- 主系统及群聊协作规则统一使用英文模板，保留用户填写的职责、资料和原始消息。
- 界面语言只作用于界面，切换语言不再取消或重新生成开场白；补全群聊错误提示和头像配色相关翻译。
- 简化群聊运行状态展示。
- 修复 APT 进度描述符与安装脚本标准输出冲突导致的字体、媒体库及桌面依赖配置失败。
- 桌面软件包配置按持续无进展判断超时，避免正常进行的慢速安装被固定总时限终止。

## 下载

- Windows x64：`AelionBot-Setup-0.19.3-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
