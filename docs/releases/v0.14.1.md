# AelionBot v0.14.1

本版减少额外模型请求和不必要的上下文压缩，仅提供 Windows x64 安装包。

- 移除程序额外调用模型生成进度说明的功能及“进度汇报间隔”设置。
- 保留模型在正常任务中主动输出的中途消息，包括流式显示和群聊中的进度消息。
- 网络失败后继续任务不再强制压缩历史，保留已有上下文和已完成的工具结果。
- 实际上下文容量不足或服务端报告超限时，仍可正常压缩恢复。
- 兼容旧版保存的进度汇报设置，该字段不再触发额外请求。

## 下载

- Windows x64：`AelionBot-Setup-0.14.1-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
