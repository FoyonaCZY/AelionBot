# AelionBot v0.57.0

## 简体中文

### 工作区媒体模型

- 在「设置 → 模型」按用途配置 Provider。同一连接可以用于对话、生图、语音识别、语音合成和视频生成，密钥只需填写一次。
- 所有 Bot 共用工作区的媒体模型和朗读音色。Bot 生成图片或视频时，也可以为本次任务指定 Provider 和模型。
- 升级时，旧 Bot 列表中第一个有效的生图模型会成为工作区默认，其余有效选择保留在对应 Provider 的模型目录中。

### 视频生成

- 支持文生视频、使用首帧图片生成视频，以及用源视频做参考、编辑或续写。可用模式取决于所选平台和模型。
- 新增 14 套协议适配，覆盖万相、Seedance、可灵、MiniMax、Vidu、Runway、Luma、Google、xAI、OpenAI Videos 兼容服务、fal 和 Replicate。画幅、分辨率和时长可以直接输入平台支持的值。
- Bot 会将生成的视频附在回复中，单个附件上限为 25 MB。查询或下载中断时，可以用任务 ID 接着取回成片。设置页也可以提交真实测试任务并播放结果，费用按平台规则计算。

## English

### Workspace media models

- In Settings → Models, choose which tasks each provider connection supports. Chat, image generation, transcription, speech synthesis, and video generation can share one connection and API key.
- All Bots use the workspace media models and voice. A Bot can also choose a provider and model for an individual image or video request.
- On upgrade, the first valid image model in the existing Bot list becomes the workspace default. Other valid selections stay in their providers’ model catalogs.

### Video generation

- Generate video from text or a starting image, or use a source clip for reference, editing, or extension. Available modes depend on the provider and model.
- Fourteen protocol adapters cover Wan, Seedance, Kling, MiniMax, Vidu, Runway, Luma, Google, xAI, OpenAI Videos-compatible services, fal, and Replicate. Aspect ratio, resolution, and duration accept custom values supported by the selected model.
- Generated videos appear as reply attachments up to 25 MB each. If polling or downloading is interrupted, use the task ID to retrieve the result. The settings page can also submit a billable test request and play the resulting clip.
