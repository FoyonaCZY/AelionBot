# AelionBot v0.27.8

发出 v0.27.6 没公开的生图回退，并修掉 v0.27.7 在 Linux / Mac 上比对 Windows PowerShell 路径失败。

## 生图

- 先按模型名猜测 Gemini `generateContent`、Responses 托管生图或 `/images/generations`。失败则试其余通道（Responses 只在 Provider 本身是 Responses 时才试）。
- 成功后按 Provider、Base URL 和模型名记下来，下次同一模型直接走记住的那条。

## 发布

- Windows 本机后台进程把就绪日志写到控制台并立刻 Flush；包装脚本在支持时打开 AutoFlush。
- `hostShell` 在模拟 Windows 时用 Windows 路径分隔符，避免 POSIX 上的单测对不上。

## 下载

- Windows x64：`AelionBot-Setup-0.27.8-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.27.8-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.27.8-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
