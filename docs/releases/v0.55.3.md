# AelionBot v0.55.3

## 简体中文

### 演示操作生成技能

- 输入框的 `+` 菜单新增“演示操作”。选“这台电脑”或“工作电脑”后做一遍操作，Bot 会把这段过程整理成以后能重复用的私有技能。
- 演示时可以打开麦克风，边做边说为什么要这样点、哪些地方每次不一样。点“完成演示”后，录音会按停顿转成带时间的文字，和每一步操作、关键画面按时间排在一起。
- 发送前可以改识别错的字、挑要附上的截图、填技能名字和补充说明，确认后再交给 Bot 保存。没有设置语音识别时也能只录操作步骤和画面。

### 固定小工具

- 回复里的交互小组件（`widget`）现在会记住里面的勾选、输入等状态，点右上角的“固定到侧栏”就会留在对话右侧，随时打开接着用。
- 每个 Bot 对话、工作会话和群聊各自保存固定的小工具；收起右侧卡片后，可以从对话顶栏重新打开。
- 群聊回复现在也能直接画图表和交互小组件。Bot 可以读取当前对话里已固定小工具的状态，或直接更新它的内容。

### 按需加载工具

- 低频工具和数量较多的 MCP 工具不再一开始全部放进工具列表。Bot 用 `tool_search` 找到需要的工具后，下一轮就能直接调用，之前的对话里用过的工具也会继续保留。

## English

### Teach skills by showing

- A new "Teach by showing" item in the `+` menu records a workflow as you do it on this computer or on the work computer, so the Bot can turn it into a reusable private skill.
- Turn on the microphone to explain what you are doing and what changes from run to run. When you click Finish, your speech is transcribed into timestamped lines and placed in order alongside the recorded actions and keyframe screenshots.
- Before sending it to the Bot, you can edit the transcript, pick which screenshots to include, and add a skill name or notes. If speech recognition isn't set up, actions and screenshots are still recorded on their own.

### Pinned widgets

- Interactive `widget` blocks in replies now keep their state, and "Pin to sidebar" at the top right keeps one beside the conversation so you can come back to it later.
- Each Bot chat, work session and group keeps its own pinned widgets; after hiding the card, a button in the header reopens it.
- Group replies can now draw inline charts and interactive widgets too, and Bots can read the state of pinned widgets in the current conversation or update them in place.

### Tools loaded on demand

- Less common tools and larger sets of MCP tools are no longer all listed upfront. Once a Bot finds a tool with `tool_search`, it becomes directly callable on the next turn, and tools already used earlier in the conversation stay available.
