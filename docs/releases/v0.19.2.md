# AelionBot v0.19.2

本版修复 Mac 交互终端启动问题，并恢复 Mac Intel（x86_64）及 Apple Silicon（arm64）发行构建。

- 修复 node-pty 的 Mac 启动辅助程序缺少执行权限导致 `posix_spawnp failed` 的问题。
- 修复打包后 Mac 终端辅助程序路径被重复改写的问题。
- 在安装依赖和 Mac 打包时准备辅助程序权限，并验证打包后的交互终端能够实际执行命令。
- 修复退出清理测试中的 Mac 目录布局兼容问题。
- 桌面软件包配置改为检测持续无进展，避免慢速虚拟机的正常安装被固定总时限中断。
- 安装器先将子进程输出写入临时日志，再读取安装进度，改善桌面软件包配置期间的输出稳定性。

## 下载

- Mac Apple Silicon：`AelionBot-0.19.2-mac-arm64.dmg`。
- Mac Intel：`AelionBot-0.19.2-mac-x64.dmg`。
- Mac 需要 macOS 15 或更新版本；同时提供 ZIP 包。
- Windows x64：`AelionBot-Setup-0.19.2-x64.exe`。
