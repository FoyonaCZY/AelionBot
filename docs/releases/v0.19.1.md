# AelionBot v0.19.1

Windows x64 语言行为修复版本。

- 主系统提示词及其工具使用、权限和协作规则统一为一套英文指令；不按界面语言维护多套系统提示词。
- 修复主会话和开场白被固定要求使用中文的问题。回复优先遵循用户明确指定的语言，再参考 Bot 语言偏好及当前用户消息；开场白默认跟随界面语言。
- 将界面语言同步并保存到模型运行端，启动时迁移已有语言选择；切换语言时取消过时的开场白生成。
- 清理旧版默认 Bot 职责中附带的固定中文要求，保留自定义职责。

## 下载

- Windows x64：`AelionBot-Setup-0.19.1-x64.exe`，也可通过客户端检查更新。
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
