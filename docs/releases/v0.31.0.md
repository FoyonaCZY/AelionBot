# AelionBot v0.31.0

## 简体中文

### 1. 权限

- 保存的命令前缀规则只对批准时的目录生效。遇到绝对路径、主目录、上级目录、Provider 或凭据路径时，需要重新确认。
- CI、开发容器、Git hook 管理器和 direnv 配置文件不再按低风险写入自动放行；规则中禁止 `rg --hostname-bin`。
- 远程 MCP 工具声明 `readOnlyHint` 后不再跳过权限模式：“询问”模式照常询问，自动模式把它当作低风险的远程读取。

### 2. 搜索与执行

- 系统 PATH 中有 ripgrep 时，`host_search_files` / `host_find_files` 先用它预筛；路径、链接、编码和脱敏检查仍全部由 worker 完成，没有 ripgrep 时按原方式遍历。
- Windows 上优先使用 PowerShell 7。`host_execute` 的超时上限提高到 600 秒，并支持 stdin；stdin 会展示在确认提示中，不会被已保存的规则覆盖。

### 3. 无界面运行

- 新增 `node dist-electron/cli.cjs`，不启动 Electron 即可运行一次 Bot 任务。密钥从 `AELION_API_KEY` 读取，支持 workspace / auto / full 三种权限；需要人工回应的操作一律拒绝，并锁定数据目录，避免与桌面端同时写入。

### 4. 上下文

- 空闲时手动压缩后，压缩控件和上下文占用环会立即刷新。

### 5. 代码结构与工程规范

这一部分不改变功能或界面，但涉及整个仓库：

- 引入 Prettier、oxlint、knip 和 EditorConfig，CI 检查格式、lint 和未使用的文件、导出与依赖。
- 源码按领域重新组织：`shared/` 放主进程与渲染进程共用、且不依赖 React 和 DOM 的代码；`electron/core/` 分为 agent、context、model、tools、vm、designer 等领域目录；`src/` 按功能分目录。lint 禁止主进程引用渲染端代码。主进程打包结果不再包含 React。
- IPC 通道集中定义在 `shared/ipc.ts`，主进程与 preload 按同一份契约做类型检查；`main.ts` 的 IPC 注册按领域拆到 `electron/ipc/`。
- Harness 的工具定义、工具分发和提示词拆到独立模块；发给模型的工具列表和系统提示与之前逐字一致。
- 拆分 `App.tsx`、文件预览、设计工作台和群聊等大组件，消除渲染端的循环依赖。
- 翻译按语言拆成独立文件，补齐 45 条缺失的英文和繁体翻译，删除 85 条已不使用的文案。
- 删除 170 条总被后续规则覆盖的 CSS 声明；逐项核对，生效样式不变。
- 错误增加稳定的错误码（`AppError`），测试改为断言错误码，不再依赖中文提示文字。提示文字本身不变。
- 测试共用辅助函数，固定等待改为轮询；删除扫描源码文本的测试和重复用例。

## English

### 1. Permissions

- Saved command prefix rules apply only to the directory they were approved in. Absolute, home, parent, provider and credential paths need a new decision.
- CI, dev container, Git hook manager and direnv files are no longer treated as low-risk writes. Rules may not include `rg --hostname-bin`.
- A remote MCP tool's `readOnlyHint` no longer bypasses the permission mode: "Ask" asks, and automatic mode treats it as a low-risk remote read.

### 2. Search and execution

- When ripgrep is on PATH, `host_search_files` / `host_find_files` use it as a prefilter. The worker still applies every path, link, encoding and redaction check, and falls back to a full walk without ripgrep.
- PowerShell 7 is preferred on Windows. The `host_execute` timeout cap rises to 600 seconds and stdin is supported; stdin is shown in the approval prompt and never covered by saved rules.

### 3. Headless runs

- `node dist-electron/cli.cjs` runs one Bot task without Electron. The key comes from `AELION_API_KEY`, with workspace, auto or full permissions. Anything that would wait for a person is denied, and the data directory is locked so it cannot be written by the desktop app at the same time.

### 4. Context

- After an idle manual compaction, the compaction controls and the context ring refresh immediately.

### 5. Code structure and engineering standards

No feature or interface changes, but the whole repository is affected:

- Prettier, oxlint, knip and EditorConfig are added; CI checks formatting, lint, and unused files, exports and dependencies.
- The source tree is organized by domain: `shared/` holds code used by both processes without React or DOM; `electron/core/` is split into agent, context, model, tools, vm, designer and other domains; `src/` is grouped by feature. Lint forbids the main process from importing renderer code, and the main-process bundle no longer includes React.
- IPC channels are defined once in `shared/ipc.ts`, and the main process and preload are type-checked against the same contract. IPC registration in `main.ts` is split by domain into `electron/ipc/`.
- Harness tool definitions, dispatch and prompts move into separate modules. The tool list and system prompt sent to the model are unchanged, character for character.
- `App.tsx`, file preview, the designer workspace and group chats are split into smaller components, and renderer import cycles are removed.
- Translations are split into one file per language; 45 missing English and Traditional Chinese translations are added and 85 unused strings removed.
- 170 CSS declarations that were always overridden are removed; the applied styles were checked and are unchanged.
- Errors carry stable codes (`AppError`). Tests assert codes instead of Chinese messages; the messages themselves are unchanged.
- Tests share helpers and poll instead of sleeping for fixed times; tests that scanned source text and duplicated tests are removed.
