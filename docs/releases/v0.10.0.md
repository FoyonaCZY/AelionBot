# AelionBot v0.10.0

本版修复 Windows 退出后 QEMU 残留的问题，并改进国内网络下桌面和办公软件的初始化安装。仅提供 Windows x64 安装包。

## 退出时关闭工作电脑

- Windows 退出客户端时会正常关闭工作电脑，保留 VM 磁盘与已写入磁盘的工作文件。
- 后台组件清理失败或超时、重复点击退出、初始化过程中退出，都不会跳过 VM 清理或在退出后继续启动新实例。
- 正常关机超时后，程序会再次核验 VM 身份并结束对应实例；Windows 的进程回退会同时检查进程句柄、程序路径、启动时间、VM UUID 和磁盘路径。
- 清除已退出 VM 的旧 PID，减少后续启动时误判为残留实例的情况。

## 国内网络与初始化

- 将桌面组件、办公软件和浏览器拆分安装，显示当前阶段、下载或安装百分比及正在处理的软件包。
- 为安装连接、下载停滞及各执行阶段设置时限。当前源失败时自动尝试清华、中科大和 Debian 官方源，并优先复用上次成功的源。
- 先完成下载，再安装和配置软件；已下载的软件包保留，重试时可以复用。
- 保留 APT 签名验证。安装源覆盖仅用于本次安装命令，不改动现有 VM 代理配置和系统 APT 源文件。
- 升级后可在工作电脑设置中点击「重试」或「继续初始化」，重新部署安装流程；已正常工作的桌面无需重新初始化。
