# AelionBot v0.42.0

这一版让群里的 Bot 拥有持续保留的人格档案，在游戏中形成共同经历，并让你查看、调整和撤回人格成长；同时每个 Bot 都能做设计，设置里新增设计系统画廊和字体库。

## 简体中文

### 人格与共同经历

- 在 AI 游戏窗口中打开“人格”，查看每位 Bot 的五维性格、出生值、成长曲线、关系和共同经历。可以按游戏或群聊筛选经历。
- 确认初稿、手动调整出生性格，或让模型根据角色设定估计初稿；也可以锁定或重置成长。MBTI 只作为参考标签。
- 狼人杀中的 Bot 会按人格选择打法，并在合理、合法的候选行动间表现出不同倾向。跨局成长参考实际行动证据；没有足够证据时保持不变。成长依据、反例和撤回入口都可以在档案中查看。
- 人格和游戏关系用于游戏及群聊，私聊仍沿用原有 SOUL。临时补位的 AI 不建立持久档案。

### 设计

- 所有 Bot 都能做原型、PPT、网站复刻、手机界面和多页文档，不再需要单独的设计师 Bot。设计稿显示在对话右上角电脑卡片下方的画布卡片里，带页面缩略图；点开先展示首页，需要文件时自己导出。
- 用哪套设计系统、哪些字体都由 Bot 按需求决定，也可以不用设计系统，拿不准时会先问你。设置里不再有默认设计系统和首选字体。
- 设置 → 设计 → 设计系统：152 套设计系统按各自的配色、字体和圆角画成样张，可以搜索、按分类筛选，也可以导入本机的 DESIGN.md 文件夹。
- 设置 → 设计 → 字体：字体库可以搜索并下载 Fontsource 开源字体、导入本机字体文件，用字体本身预览字形，也可以删除。Bot 做设计时会从字体库离线取用；不开设计任务时，Bot 也能替你搜索并下载字体到字体库，下载前会请求写入权限。

### 恢复与修复

- 对局结束后的结算与战报在写入失败或重启后可以继续完成；重置、删除或修改人格后，旧任务不会重新写回过期成长。
- 群回复发布失败后保留已完成答案，继续时不必重新请求模型；同轮其他成员较晚完成的答案也能恢复。静默文本不会丢掉附带的有效文件。
- 修复 macOS 文件搜索可能漏掉大小写不同的扩展名，以及预览页面与模态窗口的交互问题。
- 画布里点“源码”后，“源码”选项不再消失；在“编辑”里保存后，顶栏不再多出一组重复的保存按钮。

## English

### Personalities and shared experiences

- Open Personality in the AI Games window to see each Bot's five traits, birth values, growth history, relationships and shared experiences. Filter experiences by game or group chat.
- Confirm a draft, adjust birth traits, or ask the model to estimate a draft from the character's role settings. Growth can be locked or reset; MBTI is a reference label.
- In Werewolf, Bots use their personalities to choose play styles and select among reasonable, legal actions. Growth across matches uses evidence from actual actions and leaves traits unchanged when evidence is insufficient. Profiles expose the evidence, counterexamples and an undo action.
- Personalities and game relationships apply to games and group chats. Private chats keep their existing SOUL, and temporary AI seats do not receive persistent profiles.

### Design

- Every Bot can make prototypes, decks, website clones, mobile screens and multi-page documents; a separate designer Bot is no longer needed. The design shows in a canvas card under the computer card at the top right of the chat, with a page thumbnail. Opening it shows the home page first; export files when you need them.
- The Bot chooses the design system (or none) and the fonts that fit the request, and asks when unsure. Settings no longer has a default design system or preferred fonts.
- Settings → Design → Design systems: all 152 systems are drawn as specimens in their own colors, type and corners. Search, filter by category, or import a local DESIGN.md folder.
- Settings → Design → Fonts: a font library where you search and download Fontsource open-source fonts, import local font files, preview them in their own glyphs and delete them. Bots copy library fonts into design tasks offline, and can also search and download fonts into the library for you outside a task, asking for write permission first.

### Recovery and fixes

- Match settlement and reports can resume after a write failure or restart. Resetting, deleting or changing a personality prevents old work from restoring outdated growth.
- Failed group publications retain completed answers, so continuing does not require another model call. Slower answers in the same round remain recoverable, and silent text no longer discards valid attachments.
- Fix file searches on macOS that could miss differently cased extensions, and preview interactions with modal windows.
- In the canvas, the Source option no longer disappears after opening the source, and saving from Edit no longer leaves a duplicate save group in the header.
