# AelionBot v0.57.3

## 简体中文

### 流式音视频预览与 100 MB 附件上限

- 全局单个附件上限从 25 MB 提高至 100 MB，单条消息附件总大小上限从 100 MB 提高至 250 MB，覆盖聊天附件、视频生成成片交付、拖入/粘贴、工作电脑传输和文件预览。手机远程传输（25 MB）、语音识别（25 MB）和设计导出保持原有上限。
- 音视频附件和工作区媒体预览改用内置流式协议（`aelion-media://`），支持 HTTP Range 分块读取和进度条拖动，不再整文件转码为 Base64 data URL。

### 媒体生成稳定性

- 视频生成和 Higgsfield 生图在轮询任务状态时对瞬时网络异常增加指数退避重试，避免偶发断连中断等待或重复提交。
- 视频任务遇到超限、输出无效等终态错误时直接返回错误，不再提示用同一任务 ID 重复查询。
- 缓存 Higgsfield 参考图字段的公开目录查询结果，并按源素材 MIME 类型保留 OpenAI 视频编辑上传文件的 `.webm` 后缀。

## English

### Streaming media previews and 100 MB attachments

- Raised the single-attachment limit from 25 MB to 100 MB and the per-message total from 100 MB to 250 MB across chat uploads, generated video delivery, drag-and-drop/paste, work-computer transfers, and file previews. Mobile remote transfers (25 MB), speech recognition (25 MB), and design export limits remain unchanged.
- Audio and video previews now stream through an internal custom protocol (`aelion-media://`) with HTTP Range support for seeking instead of base64 data URLs.

### Media generation reliability

- Added exponential backoff retries for transient transport errors while polling video generation and Higgsfield image jobs, avoiding unnecessary interruptions or duplicate submissions.
- Terminal video output failures (such as oversized or invalid outputs) are returned directly without prompting to re-poll the same task ID.
- Cached Higgsfield reference-field schema lookups and preserved `.webm` extensions when uploading WebM videos for OpenAI video edits.
