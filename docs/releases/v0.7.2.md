# AelionBot v0.7.2

本版修复聊天、附件、模型设置与工作电脑初始化问题，仅提供 Windows x64 安装包。

## 修复内容

- 修复上下文不足后反复继续却没有进展的问题。较大的近期工具结果可通过归档摘要释放空间；容量仍不足时明确显示原因，并提供对应 Bot 的模型设置入口。
- 继续任务会沿用原始用户要求和执行记录，不再重复插入固定的用户消息。群任务和 Bot 私聊任务恢复后，结果仍交付到原会话。
- 修复连续新增 Provider 时误覆盖前一条配置的问题。新增和编辑使用不同操作名称，保存后返回列表，再次新增会打开空表单。
- 上下文容量输入框支持清空和重新输入，修复无法删除开头 `0` 的问题。
- 文件夹拖入后可选择设为工作目录或打包为 ZIP 附件。导入错误可关闭，正常发送后会清除；切换 Bot 时，晚到的导入结果不会进入其他会话。
- 统一主会话、私聊、群聊和文件预览的 Markdown 表格渲染，保留表格中的文字格式与成员提及。
- 修复群聊将内部消息 JSON 显示为正文的问题，并处理旧记录的正文和列表摘要显示。
- 弹窗会同步 Windows 原生标题栏的背景色，嵌套弹窗关闭后仍保持父弹窗的遮罩。
- 系统镜像下载支持宿主机现有系统代理、断点续传、失败重试及经过校验的 Debian 官方备用地址。
- Windows 新建工作电脑改用现有 Debian 软件源安装 Chromium，避免初次安装依赖 Google 的 Chrome 下载地址。已有 Chrome 继续使用。
- 保留 VM 现有代理、软件源及工作环境版本，不要求已有工作电脑重新配置。
- 同步权限模式选择框的界面调整。

## 下载

- Windows x64：`AelionBot-Setup-0.7.2-x64.exe`，也可在客户端检查更新。
- 附带 `latest.yml`、差分更新文件和 `SHA256SUMS.txt`。
- 本版没有 Mac 安装包。Mac 用户可继续使用 [v0.7.1](https://github.com/FoyonaCZY/AelionBot/releases/tag/v0.7.1)。
