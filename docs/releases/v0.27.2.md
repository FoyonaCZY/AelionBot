# AelionBot v0.27.2

对照 OpenDesign 理清 Provider、对话模型和生图模型，避免把聊天配置套到出图上。

## 生图

- 生图配置只选 Provider 和模型，不再出现推理强度和上下文容量。
- 按模型名分流：Gemini / Imagen 走 `generateContent`，Responses 走托管图片生成，其余走 OpenAI 兼容的 `/images/generations`（没有 base64 时会下载返回的 URL）。

## 设置

- Provider 列表标出协议。编辑时先填连接，Responses 工具单独一块，温度和备用模型收进「对话默认」。
- 模型目录是给选择器用的名单，可筛选；改一条目录不再关掉整个编辑页。
- Bot 资料把对话模型和生图模型分开说明。

## 下载

- Windows x64：`AelionBot-Setup-0.27.2-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.27.2-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.27.2-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
