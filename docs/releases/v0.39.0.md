# AelionBot v0.39.0

## 简体中文

### 工作电脑改成浮窗

- 右侧固定的一栏改成浮在对话右上角的卡片，对话区多出原来右栏的宽度。卡片不会挡住顶栏和输入框，打开时消息会避开它。
- 工作电脑的画面铺满卡片上半部分；设置、关闭和全屏按钮在鼠标移上去时才出现。电脑未启动时只显示一个启动按钮。
- 定时任务每条一行，显示名称、下次执行时间和开关；任务较多时才出现筛选。
- 卡片可以关闭，应用会记住你的选择。关闭后，单聊和群聊的顶栏都有一个电脑按钮可以重新打开它，电脑运行中时按钮上有一个绿点。

### 中间步骤更好读

- 修复命令输出在中文 Windows 上显示成宋体的问题，现在使用应用自带的等宽字体，`->`、`://` 等也不再被合成连字。
- 步骤说明和耗时等标签改用界面字体，只有命令和路径保留等宽字体。

### 群聊修复

- 退出或重启应用时，只有确实还有工作没做完的讨论才会标记为中断；已经结束的群聊不会再出现「继续本轮讨论」。
- 狼人杀对局卡片重新始终显示在群聊里，不会在看过战报后消失。

## English

### The work computer floats in a card

- The fixed right column is now a card over the top right of the conversation, so the conversation gains that column's width. The card never covers the header or the composer, and messages keep clear of it while it is open.
- The work computer's screen fills the top of the card; settings, close and full screen appear on hover. When the computer is off, the card shows a single button to start it.
- Scheduled tasks take one line each, with the name, the next run time and a switch. Filters appear only once the list is long.
- The card can be closed and the app remembers it. A computer button in the header of single and group chats brings it back, with a green dot while the computer is running.

### Easier-to-read steps

- Command output no longer falls back to SimSun on Chinese Windows; it uses the bundled code font, and `->` or `://` are no longer joined into ligatures.
- Step details and labels such as durations use the interface font; only commands and paths stay monospace.

### Group chat fixes

- Quitting or restarting the app now interrupts only discussions that still had work in flight; finished group chats no longer show "Continue this round".
- The Werewolf match card always shows in the group chat again instead of disappearing once its report has been viewed.
