# AelionBot v0.27.5

修掉 v0.27.4 把 electron-builder 缓存放到仓库目录后，Mac 生成 icns 失败。

## 发布

- `ELECTRON_BUILDER_CACHE` 改到 runner 临时目录，不再落在带 `"type": "module"` 的仓库里，避免 `icon-tool.js` 把 `require` 当成 ESM。

## 下载

- Windows x64：`AelionBot-Setup-0.27.5-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.27.5-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.27.5-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
