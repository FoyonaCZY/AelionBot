# AelionBot v0.38.0

## 简体中文

### 自动审核更少打扰

- 本机权限为「自动」时，命令先按真实语法拆开逐段检查。Windows 上用系统自带的 PowerShell 解析器（只解析，不执行），macOS 和 Linux 上用严格的分词规则。每一段都只是在当前工作目录内列目录、读文件、搜索、过滤或格式化输出，就直接执行，不再等待审核模型。只要有一段写入、删除、运行脚本、联网、重定向到文件或越出工作目录，仍按原来的方式审核。
- 新增可以直接执行的只读命令：只读的 git 子命令（status、log、diff、show、branch 等）、对指定文件的 rg 搜索，以及 node、python、npm 等常见工具的版本查询。仓库配置或钩子里有会运行程序的设置时，git 命令仍需审核。
- 同一次任务里已经由审核模型放行的操作，再次执行完全相同的操作时不再重复审核。你发出新消息、换了任务或任务结束后，会重新审核；转人工和拒绝的结论不会被复用，也不会变成保存的命令规则。
- 读取本次任务刚用文件工具写出的文件（例如渲染出的预览图）不再需要审核，敏感文件除外。
- 审核模型现在能看到本次任务实际写过的文件和最近的步骤，用来判断操作是否承接上一步；这些信息不算授权，其他 Bot 的消息也不算人类授权。

## English

### Fewer automatic-review interruptions

- In Auto host permission mode, commands are split by their real syntax and checked part by part: with PowerShell's own parser on Windows (parse only, never run) and strict word rules on macOS and Linux. When every part only lists, reads, searches, filters or formats files in the current workspace, the command runs without waiting for the review model. Any part that writes, deletes, runs a script, uses the network, redirects to a file or leaves the workspace is reviewed as before.
- More read-only commands run directly: read-only git subcommands (status, log, diff, show, branch and others), rg searches of named files, and version checks for common tools such as node, python and npm. git commands are still reviewed when the repository's config or hooks would run a program.
- Within one task, an operation the review model already allowed is not reviewed again when it repeats exactly. A new message from you, another task, or the end of the task brings review back; "ask" and "deny" results are never reused and never become saved command rules.
- Reading back a file the task just wrote with a file tool (for example a rendered preview image) no longer needs review, except for sensitive files.
- The review model now sees which files the task actually wrote and its latest steps, so it can tell when an operation follows from the previous one. This is not treated as permission, and messages from other Bots are not treated as yours.
