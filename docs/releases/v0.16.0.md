# AelionBot v0.16.0

本版补齐基础工具，修复图像模型兼容和群聊工具历史问题，并新增个人资料设置，仅提供 Windows x64 安装包。

- 新增本机和工作电脑交互终端，支持持续运行、读取输出、发送输入和停止会话。
- 新增多文件补丁工具，支持创建、修改、移动和删除文件，并在写入前校验补丁。
- 新增隔离的 JavaScript 工具编排，支持并行调用工具；本机操作沿用已有权限设置。
- 新增会话内提问、本机图片查看、统一工具发现、MCP 资源模板和网页搜索、读取工具。
- 修复不支持图像的模型被旧图片持续阻塞的问题；当前图片无法处理时提供明确提示，并支持配置模型图像能力。
- 修复群聊进度消息插入工具调用与结果之间导致请求失败的问题；旧历史修复前保留备份，不重复执行工具。
- 设置新增个人资料，可填写称呼、角色和背景，供 Bot 在主会话、私聊和群聊中使用。
- 新增外观设置，支持浅色、深色和跟随系统主题，以及字体、字号、行距和显示比例调整；内置界面与代码字体可离线使用。
- 调整设置窗口及定时任务界面，统一控件、空状态和文字样式。
