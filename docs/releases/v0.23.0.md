# AelionBot v0.23.0

设置自动保存、预览反馈，以及工作电脑连接更稳。

- 默认模型、审核模型和存储上限改完即保存，不再需要点保存。去掉多余说明。「更新后自动回收」默认关闭。
- 预览里可以对当前可见区域截图并写下修改意见，发给对应会话。
- 工作电脑桌面在真正就绪后再开放操作；远程画面连接失败会自动重试。

## 下载

- Windows x64：`AelionBot-Setup-0.23.0-x64.exe`，也可通过客户端检查更新。
- macOS ARM64：`AelionBot-0.23.0-mac-arm64.dmg` / `.zip`
- macOS Intel：`AelionBot-0.23.0-mac-x64.dmg` / `.zip`
- 附带自动更新清单、差分更新文件和 `SHA256SUMS.txt`。
