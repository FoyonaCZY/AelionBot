# 设计字体

设计任务的字体由 Bot 按设计自己挑选，并用字体工具获取和应用。需要指定哪款字体，直接在对话里说，也可以把 WOFF2、WOFF、TTF、OTF 文件交给 Bot 导入。修改只写入受管字体样式，保留其余源码，并遵守当前任务的权限。

## 项目资源

字体通过 Fontsource 元数据与固定版本的官方包获取，首次下载后保存在应用数据目录的 `font-cache`，后续可离线复用。下载范围限于已登记的字体 ID、字重、样式和语言切片，不接受任意下载 URL。中文字体保留 Unicode 分片及字符范围。

项目中的资源位于：

- `assets/fonts/fonts.json`：字族、字重、文件 hash、来源、版本及授权记录。
- `assets/fonts/fonts.css`：本地 `@font-face` 声明。
- `assets/fonts/<字体>/`：实际字体及授权记录。

导入字体读取文件中的真实元数据。用户提供的字体会记录来源与已有版权信息；应用不会据此声明获得了额外使用授权。导入不会安装或修改系统字体。

## 字体库

设置 → 设计 → 字体是跨任务共用的字体库：可以搜索并下载 Fontsource 开源字体（拉丁字族默认 400 和 700，中文字族默认 400），也可以导入本机的 WOFF2、WOFF、TTF、OTF 文件。每张卡片用字体本身渲染字形和样句，可以删除。

字体库保存在应用数据目录的 `font-library`（`library.json` 加字体文件，目录结构与项目 `assets/fonts/` 一致）。Bot 用 `design_fonts list` 能看到字体库，`acquire` 时字体库已有的字族会离线复制进任务，不再联网；文件被改动或缺失时拒绝复制。从字体库删除字体不影响已经复制进任务的副本。字体库只是可用资源，选哪款字体仍由 Bot 决定。

Bot 不开设计任务也能用 `design_font_library` 列出字体库、搜索 Fontsource，并把字体下载进字体库。下载前会请求对 `font-library` 的写入权限，被拒绝时不写入任何文件。

“检测”检查字体文件、受管 CSS 和文字覆盖；留空时检测当前 HTML 的文本。文件缺失或已变更会在列表中标记，禁止继续应用。检测文字覆盖不等于对全部页面布局进行验收。

## 导出

- 设计任务 HTML 的普通下载会内嵌本地资源，包含字体、CSS 和图片。
- 字体面板的“导出项目”保存 ZIP，包含当前 HTML 实际引用的资源及相应字体授权记录。
- PDF 使用同一份本地资源，等待实际文字所需的字体、字重和图片加载后打印。资源失败时返回错误。
- 当前导出面向静态 HTML；模块构建项目需先生成静态产物。无法可靠收集的依赖会明确报错。
- 本版未实现 PPTX 字体嵌入；HTML 预览应用字体不会更改 PPTX 文件。

## 设计工具

Bot 可以按设计需求自主搜索并下载开源字体，无需用户手动操作。先查询项目字体，再搜索缺少的字族，使用搜索返回的 Fontsource ID 下载，最后用下载结果中的项目字体 ID 应用并检查文字覆盖。用户明确指定的字体与品牌要求优先；下载失败时报告原因，不假称已经应用。

`design_fonts` 查询、获取、导入或检测项目字体；`design_font_apply` 应用到 HTML；`design_export_project` 导出 ZIP；`design_export_pdf` 导出 PDF。字体下载与用户导入写入同一项目资源库，修改遵守设计任务的目录和权限边界。下载字体的最终页面使用本地引用，仍不直接引用远程字体 CSS。
