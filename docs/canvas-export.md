# 画布导出

在设计画布右上角点击“导出”，选择格式后指定保存位置。源码或画布内有未保存的修改时，会先让你保存或放弃这些修改。

| 格式 | 用途 |
| --- | --- |
| Sketch（.sketch） | 交给设计师继续修改，或导入 Figma |
| PDF | 查看、交付和打印；分页采用网页的打印样式 |
| PNG | 整页图片，保留浏览器实际渲染效果 |
| SVG | 基础矢量图形；复杂网页效果可能与预览不同 |
| HTML | 包含本地字体、样式和图片的独立网页 |
| 项目 ZIP | 网页及引用的本地资源、字体授权文件 |

以上格式适用于设计任务中的本地 HTML 文件，普通文件预览使用“打开”菜单：默认应用、选择其他应用、打开所在文件夹、另存为。设计画布仍使用“导出”。本机原文件可以直接打开；原路径不可用的附件及工作电脑文件会准备本机副本，外部应用的修改只影响这份副本。导出以当前预览的视口尺寸重新渲染已保存源码，不包含尚未保存的编辑或临时交互状态。

## Sketch 中的内容

文件包含两个画板：

- **保真图层**：尽量保留可编辑的形状、线性渐变、边框、阴影、圆角和 SVG 路径。本地字体尽量转为矢量轮廓；字体不支持转轮廓时保留局部图片。
- **可编辑文字**：在相同布局中保留可识别的文字图层。接收端需要安装相应字体，否则可能替换字体、改变排版。复杂效果已经转为图片的区域，其内部文字也属于图片。

滤镜、旋转、蒙版、复杂背景、伪元素等无法准确映射的效果会转成局部图片，以保留外观。每个画板还包含隐藏且锁定的“原画面参考”层，显示后可与转换结果校对。字体授权文件保存在归档的 `licenses/` 目录中；Sketch 文件不会安装字体。

网页的响应式规则、自动布局、链接和交互逻辑不会转换成 Sketch 原生行为。需要这些能力时，同时交付项目 ZIP。SVG 也不会完整复现所有 CSS 效果。

PNG 和 Sketch 最多支持 3200 万像素，单边最多 16000 像素。超长页面可以拆分导出，或改用 PDF。导出使用本地资源；无法加载的资源会返回错误，不会静默删除后继续交付。

## 实现与验证

Sketch 归档依据[官方文件格式](https://developer.sketch.com/file-format/)生成，使用官方 JSON Schema 验证 document、page、meta 和 user。测试覆盖字体轮廓、可编辑文字、图片引用、裁切、渐变以及保存失败时保留已有文件。

实际 Electron 渲染验证包含 PDF、PNG、SVG 和 Sketch 文件生成，并对导出的 Sketch 图层进行重建比对。此比对不等同于 Sketch 或 Figma 的真实导入验证；当前 Windows 开发环境尚未完成接收端应用验收。
