# 画布缩放与反馈

设计工作区将聊天栏保持在 300–380px，画布使用剩余宽度。网页显示比例独立于应用缩放，100% 与应用界面的 CSS 尺寸一致；PDF 文档默认适应宽度，幻灯片默认整页。窄窗口也可展开画布。展开仅改变布局，不重新创建预览，因此页码、比例和提问草稿保持不变。

圈选提问与元素提问完成后切回预览，并把原生网页的键盘焦点交还提问输入。提问底栏位于原生 WebContentsView 范围之外。用户可逐条选择、编辑说明、删除标注；发送失败保留内容，成功后清空临时标注。标注随截图发送，并保存到当前设计任务。

网页标注使用记录时的整页 CSS 尺寸作为坐标基准；元素标注额外保留 selector、data-design-id 和文字信息，重新打开时优先锚定真实 DOM。反馈携带当前视口和滚动位置，截图仅含可见区域。发送前等待原生页面完成布局，避免底栏高度变化造成坐标滞后。

持久批注按文件、标注 ID 或几何范围去重，不会把不同位置的相同问题合并。反馈文件必须位于所选设计任务目录内。
