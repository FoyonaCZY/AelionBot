# 本地 Laya 群聊决策实验

用户在「群聊 → 群聊设置 → 实验 · 决策模型」中点击「一键下载并启用」。应用检查操作系统和架构：Apple 芯片 Mac 安装 Laya Mac 版，Windows x64 与 Linux x64/arm64 安装 Laya 标准版。Intel Mac 等未验证环境会显示不支持。此设置适用于所有群聊。默认不下载、不启动推理进程，也不显示群聊决策记录及相关标识。下载后可暂停或重新启用；只有模型就绪时才参与群聊和游戏的候选判断。其他模型家族需要单独适配输入、输出和安装方式，不能只替换模型 ID。

群聊中，每个 Bot 独立收到事件，并让本地 Laya 从「旁听、参与」中选择下一步。若用户在当前消息中明确要求不执行且静默，系统按该要求旁听，并保留 Laya 原始选择和分数。旁听处理收件且不发言；参与启动该 Bot 绑定的主模型，由它回复、使用工具或按群任务协议认领工作。主模型读到更多上下文后可以调整。Laya 不提供新的执行授权，用户停止群聊时会取消当前执行。Laya 不可用时退回主模型自主判断。狼人杀目前仍只记录 Laya 候选，不控制游戏行动。

群聊决策只输入当前 Bot 的角色（最多 500 字）、最新最多 3 条收件和本轮开始前最多 2 条群消息。只有该 Bot 有未完成任务时，才附上任务标题和状态；续聊、定时触发或后续事件看不到原请求时，最多补 400 字根任务上下文。当前消息最多 600 字，前文最多 300 字。成员名单、其他 Bot 的任务、工具执行记录和私聊不传给 Laya。

群消息下方每行显示最多 3 位 Bot。每张小卡只显示 Bot 名称、是否参与，以及「旁听／参与」两项分数。Laya 不返回自然语言推理过程；候选分数也不是正确率。

决策写入应用数据目录的 `laya-decisions.jsonl`。文件仅供本地应用使用（权限 0600）；决策记录包含送给 Laya 的精简消息快照，因此可能含有群聊内容。

用户下载并启用后，应用在低优先级 Python 进程中预热模型。预热期间直接由主模型处理消息；就绪后最多保留 3 个在途预测，额外请求直接回退。单次等待预算为 5 秒（包含排队），超时会退出推理进程并在本次应用会话中回退主模型。日常启动预热超过 120 秒会退出，首次下载模型权重的等待上限为 15 分钟。MLX 空闲缓存上限为 64 MiB，这不限制模型权重和推理所需的活动内存，也不限制 GPU 使用率。Python 进程降低 CPU 调度优先级，常用计算库线程数设为 2。

启动日志记录预热耗时和 MLX 内存占用；决策日志另记实际推理耗时、活动内存和缓存大小，用于区分加载、排队与推理延迟。旧版三态记录会归并为「旁听／参与」展示。

当前支持两种运行时，使用相同的多语言模型。「一键下载并启用」自动准备 `uv` 和 Python 3.12；若 Apple 芯片 Mac 已有可用 `uv` 则复用，否则下载对应平台且经过 SHA-256 校验的版本。依赖安装在应用数据目录的 `laya-runtime/`，模型权重由运行时在首次加载时下载：

| `AELION_LAYA_RUNTIME` | Python 包 | 默认模型 |
| --- | --- | --- |
| `standard` | `laya` | `convaiinnovations/laya-multilingual` |
| `mlx` | `laya-mlx` | `aac6fef/laya-multilingual-mlx` |

开发者可以在 macOS Apple 芯片上预装 MLX 环境，再在设置中点击下载以复用此环境：

```bash
uv venv .local/laya-venv --python 3.12
uv pip install --python .local/laya-venv/bin/python laya-mlx
AELION_LAYA_RUNTIME=mlx AELION_LAYA_PYTHON="$PWD/.local/laya-venv/bin/python" pnpm dev
```

环境变量仅让用户点击下载后复用已有 Python 环境，不再直接启用 Laya。开发版也会在 Apple 芯片 Mac 点击下载时检查 `.local/laya-venv/`，避免重复安装。没有可复用环境时，群聊设置会自动准备下载工具并安装系统对应的运行时。首次加载会下载对应权重；失败时本轮 Bot 和游戏照常执行。

这台 Apple 芯片 Mac 的一次短中文输入测量：MLX 进程峰值约 1.08 GiB，标准版约 2.55 GiB。两份 Python 环境分别约 264 MB、751 MB，两份模型缓存合计约 1.2 GB。实际占用随输入、运行时版本和缓存状态变化。

群聊决策属于实验功能。
