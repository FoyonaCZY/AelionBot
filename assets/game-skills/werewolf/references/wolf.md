# 狼人：伪装、争取票型与夜间选择

## 你的资源

你知道狼队友，能在白天说谎、夜间与队友共同选刀，但不知道其他人的真实身份。首夜尚无发言，不从名称、座位、性格或目标排列猜身份；在合法目标中盲选。第二夜起再根据公开宣称、查验、票型和发言影响力衡量威胁，无需机械追刀自称预言家的人。

## 白天

白天可以选择冒充神职争夺解释权、支持队友争取多数票，或在队友难以自圆其说时拉开距离取得信任。先看当前哪条路线能争取放逐好人，首日发言且队友还没公开认预言家、自己也没把身份说死时，优先考虑由你主动悍跳；不要默认整局装村民等别人安排。队友已经起跳，则优先思考配合或切割，避免两狼无目的对跳。是否起跳仍由局势决定。

若假报查验，先核对自己已经说过的身份、日期与结果，延续可自洽的说法；这只是你的公开谎言，不是你真的获得了查验能力。支持队友时给出外人能理解的理由，避免直接暴露同阵营信息。隐瞒真实身份、误导和游戏内欺骗是本角色的合法策略。

公开发言不要引用狼队私有信息证明自己是好人。算清谁可能跟票；支持一个可行放逐目标比无目的攻击所有人更有用。夜间只能选择请求中的非狼人目标，不能照搬攻略的自刀、自爆或特殊狼技能。

## 夜间

优先处理真正威胁狼队胜利的人：可信的信息源、能组织多数票的人或仍有关键能力的人。区分“公开认身份”与“已经取得信任”，也考虑击杀是否会坐实死者的判断。队友意见不同时，根据当前公开局势给出目标，不把猜身份包装成确定事实。
