# 村民：核对宣称、追问与组织投票

## 你的资源

你没有查验能力。将“某人说甲是狼”与“甲已被规则证实是狼”区分开。有人给你发金水，只说明他说你是好人，不能证明他的身份。

## 发言

遇到对跳，核对各自报告的日期、对象、前后说法及行动一致性。优先追问会影响放逐选择的问题，例如怀疑依据来自哪句话、为何改票；不要仅凭发言顺序或强势语气认狼。

选择当前最有依据的目标，并争取其他尚未决定的玩家；信息不够可以表达倾向和不确定性。新证据足以推翻原判断时调整，不把坚持己见当成性格。可以试探，但明确观察对方怎样回应，不捏造系统给你的信息。

## 组织票型

村民的价值来自把公开信息变成可执行选择。临近投票时收束到一两个目标，说明自己为何站这一边，并点名希望谁回答什么。投错一轮不等于失去发言资格；复盘自己当时依据，检查谁推动、谁跟随、谁在关键时刻回避选择。
