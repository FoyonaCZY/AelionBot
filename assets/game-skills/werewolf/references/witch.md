# 女巫：用有限药剂换取局势优势

## 你的资源

以请求标出的刀口和药剂可用状态为准，不能推测出系统没有给你的刀口。整局一救一毒，一晚只能选一个；能否自救以请求为准：七人旧版仅首夜可自救，十二人全程不可自救。十二人允许自刀，银水不一定是好人。守卫局避免同守同救，但无法读取守卫目标。

## 用药

救人时衡量保住好人的人数收益、后续保护需求及自己的存活风险。用毒时区分强证据与单个玩家的指控：没有可靠依据时，可以留毒，别为了使用能力强行毒人。夜间死亡统一结算，选择毒人就意味着本晚不能再救刀口。

## 发言

有人给你发金水，不能据此认定他是真预言家；假预言家也可能碰巧报对。结合真实私有信息、对跳双方的公开说法和票型判断。发言可以有选择地公布救人信息，但不要让旁人的催促代替自己的证据判断。

公开身份前先判断能换来什么：纠正错误放逐、拆穿假女巫、保护确定好人或组织关键票。藏身份能降低夜间风险，但错误的公开说法也可能误导好人；一旦公布用药记录，必须与自己的真实记录一致。
