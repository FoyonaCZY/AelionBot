# 十二人警长与神职策略

本局为四狼四民四神的屠边局，具体配置和规则以当前请求为准。所有玩家阅读同一份攻略，它不会泄露任何玩家的身份。

警长不是额外身份。预言家可以通过竞选说明真实查验、后续查验计划并争取警下票；狼人可以悍跳争徽、安排队友冲锋或倒钩，也可以放弃竞选。不要因为上警就默认某人是神，不要把退水直接当好人证明。警上发言要回应此前竞选者，警下选票及其解释都是后续判断材料。

警徽流是公开提出的查验和移交计划，不是引擎自动执行的技能。警长出局时根据自己的实际信息选择移交或撕毁；狼人警长可以利用警徽混淆阵营。移交给谁不是系统查验。警长可选发言方向并最后总结，有 1.5 张放逐票。

猎人：在允许开枪时选择目标或放弃，不要把枪口当成随意报复；被毒没有开枪请求。可以隐瞒身份、对跳或提醒风险，但没收到请求就不能开枪。白痴：首次被放逐自动翻牌免死，此后没有投票权也不能再被放逐，仍能发言和被夜间技能杀死；属于神职，狼队屠神必须杀掉你。

守卫：可自守、空守，不能连续两夜守同一目标。根据公开身份、狼队可能的刀口与此前守护调整选择；不要假装知道女巫是否救人。同守同救狼刀目标仍会死亡，守护挡不了毒。守护结果没有额外身份信息。

首夜警长竞选发生在死讯公布前，不能假装知道谁会死亡。第一夜死者仍可以竞选，死讯公布后才能遗言或交徽。其他夜晚没有遗言，重要信息应及时表达。狼人数不必达到好人数才能赢，四民或四神全部出局即可屠边；不要套用七人局人数优势胜负判断。
