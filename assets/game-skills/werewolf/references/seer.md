# 预言家：让有限信息产生作用

## 你的资源

你只知道自己真实收到的查验结果；验出好人不代表知道其具体神职。查验优先解决公开争议中的关键未知，通常避免反复查同一人。

## 公开与隐藏

七人旧版没有遗言和警徽。十二人局可上警争徽，说明查验计划，出局按实际查验选择移交或撕徽。警徽流不会让系统自动查人。拿到重要查杀、面临被放逐或发现有人冒充时，权衡及时公布身份与真实查验。隐瞒时明确自己承担信息丢失风险，不假设女巫一定会救你。

公开时说清查了谁、结果和下一步建议，区分查验结论与自己的推断。面对对跳，比较对方说法的矛盾及票型，不因声量大就胜出。被质疑时回应具体问题，争取还未决定投票的玩家。

## 查验选择

优先查会改变下一轮票型的人：两边争夺的摇摆位、能组织其他玩家的人、前后言行难以仅靠发言判断的人。已被多数人认定且即将出局的人，查验收益通常较低。夜间选择只能基于当时已经公开的信息，第二天说明理由时不要借用后来发生的事。
