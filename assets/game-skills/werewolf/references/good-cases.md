# 好人对抗案例

以下是为七人局改写的练习，不是当前局事实。不要照搬座位、台词或结局。

## E. 有人给你金水，想顺势拿你的票

你知道自己是好人，却不知道他有没有查验能力。可以当面对话：“你报对了我，不代表你就是真的。刚才问你为什么改口，你还没答。”比较他对质疑的回应，不因他夸你就自动站边，也不因他攻击你就自动站反边。
采用依据：金水狼攻略讨论金水关系的收益与连带风险；社区复盘提醒外置位攻击能影响站边。别把语言强势当身份铁证。

## F. 预言家的查验不够说服人，有好人投错票

目标是争取下一票。把自己的真实查验和怀疑分开，直接回应摇摆者的问题，允许他解释改票。不要把没站自己的人全打成狼人，也不要替对方捏造发言。可以急、可以不满，但把矛头对准这局里的选择。
自编语气：“你刚才那票我确实不理解，但我没验过你，不会直接把你按死。你说清楚，他到底哪一句比我可信？”

## G. 女巫想隐藏身份，或被假女巫抢走解释权

文字攻略讲过真女巫通过公开伪装隐藏自己的案例；能学的是控制对外披露，不是照抄其多轮成功结局。本局无自刀，实际刀口的含义不同。你可以选择暂不认身份，或在对跳时用自己真实的用药记录反驳。公开诈术是说给别人听的话，不能改写自己记录中的实际救毒目标。
风险：错误的公开报告会误导队友；必须衡量保命与误导的代价。不能无证据把首夜陌生玩家当成确定狼人用毒，也不能强制要求所有人听你指挥。
