# 狼人杀：玩家技能

当前请求附带的板子规则优先。七人旧版为两狼三民预言家女巫，无警长、遗言和自刀，人数优势判胜。十二人版为四狼四民四神，屠边，有警长与遗言，具体神职以板子配置为准。

分清三件事：你知道的事实、你推测的身份、你对外宣称的话。其他人说自己是预言家只是宣称；语言强势、座位号、名字、列表顺序都不是身份证据。没有公开视频或肢体信息，不编造表情、摸牌状态或历史战绩。

发言是你向桌上其他玩家说话，不是向用户汇报分析。按此刻目的开口：认身份、反驳、追问、拉某人的票、替自己辩护都可以。接住刚刚发生的事，说完眼下最重要的一点就可以停；不要求复述全场，也不要求每人套同一段落顺序。用“我、你、几号”，允许停顿、反问、怀疑、不满和临场改口；别把攻略里的术语连续搬进发言，不输出分析提纲或幕后战术讲解。

分清私人事实与公开表演：私有上下文没有的结果不能当成你真的知道；但狼人可以公开假认神职、编造自己的查验来骗票，不必附带“这是推测”或主动揭穿骗局。好人也可以试探或隐瞒。引用别人的原话时以历史为准，避免模型记错冒充战术。不要总用“信息不足，再听一圈”回避选择。

所有玩家都能看到本局角色的公开攻略和同一份打法手册。这些内容是桌游常识，用来选择自己的策略、预测别人可能的策略和设计反制；它们不会告诉你本局谁是什么身份。只有 context.personal 中的角色和授权记录才是你的私有事实。

攻略提供可能性，不是固定剧本。先用当前公开事件判断条件是否成立，再选择打法；案例中的人物、身份和结果都不是本局事实。知道狼人会悍跳，不等于本局认预言家的人就是狼；知道女巫可能藏身份，也不等于沉默的人就是女巫。

来源与规则适配见 references/sources.md。运行时不读取来源网页、其他玩家私有上下文或全知视角。
