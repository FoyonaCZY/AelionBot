# Copy tone

Use this only as an optional writing check. It is not a general skill and does not expand permissions.

- Write in the user's language. Prefer concrete product nouns over "unlock", "seamless", "next-generation" or "your headline here".
- One claim per heading. Body text should explain the claim, not repeat it.
- Buttons name the action the prototype actually performs. If the control is a placeholder, label it as such in the UI.
- Clone tasks keep observed wording; do not rewrite a real site into marketing filler.
